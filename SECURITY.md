# Security reports

Report an issue privately through the repository's Security tab when
private reporting is enabled, or ask the repository owner for a
private channel before sharing details. Include the affected chapter,
crate or revision, prerequisites, observed behavior, and the security
property at risk. Keep credentials, personal data, and production
addresses out of reports and classroom examples.

The book uses historical dependencies for reproducibility. Each
networked, storage, or cryptographic project must document its threat
model, dependency versions, and limits. Evaluate deployment dependencies
against the security requirements of the deployment environment.
