### EX-C005-01 — Translate under permissions

**Beginner.** Specify a translation function for the chapter's
16-byte pages. It accepts an address, a process map, and an
operation, and returns a physical address or an unmapped or
permission error. Use A's read/write page 2 in frame 9 and B's
read-only page 2 in frame 12. Test both kinds of success, a
write in B, and address `0x30` in each process. Assume supplied
frame numbers fit after multiplication and adding any offset.

### EX-C005-02 — Keep a scheduler trace

**Beginner.** Model one CPU with one step per unit of time.
A starts a read in interval 0–1 and waits until time 3. B
starts runnable and needs two consecutive or separate steps.
When both are runnable, prefer A. After resuming, A needs
one step. Produce the running thread and the completion
times. Then delay readiness until time 4 and identify the
idle interval. Do not accrue CPU steps for an idle interval.

### EX-C005-03 — Implement a parity recognizer

**Intermediate.** Accept a list containing only bits and
return whether it contains an even count of 1s. Use one bit
of memory for the state. Test empty input, `[1]`,
`[0, 0]`, and `[1, 0, 1, 1]`. Give a loop invariant
and count work as a function of input length.

### EX-C005-04 — Recognize bounded nesting

**Challenge.** Given a stream containing only parentheses
and a nonnegative maximum depth `D`, return success for
balanced input whose depth never exceeds `D`. Return an
error at the first illegal closing or over-limit opening,
or an unfinished error on end of input. Test empty input
at depth 0 and, at depth 1, `()()`, `(()`, `)(`, and
`(`. Check limits before modifying the counter.

### EX-C005-05 — Distinguish an interpreter error

**Intermediate.** Specify an interpreter for one byte of
state, initially 0. Opcodes are `0` (keep),
`1` (toggle the least significant bit), and `2` (halt,
returning the state). Other values are invalid. An input
without a halt yields a missing-halt error if it runs out
after only valid operations. Verify `[1, 0, 1, 2, 9]`,
`[1, 2]`, empty input, and `[0, 7, 2]`. Explain
whether the implementation is free to inspect bytes after
the halt.
