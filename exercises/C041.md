### EX-C041-01 — Choose outcomes for a stock lookup

**Beginner.** A stock shelf search permits an empty result, while a
reservation requires one existing shelf. Give the Rust return shape
for each operation and explain what a missing shelf means.

### EX-C041-02 — Check exact depletion

**Beginner.** Starting from five units, reserve exactly five, then
one more, then zero. State the observable result and availability
after each request. Verify with assertions.

### EX-C041-03 — Reverse a valid reservation

**Intermediate.** Write a small function over `total` and `available`
that releases a request. Assume `available <= total` upon entry.
Return the new availability or the previous held count as an error.
Show why the success path cannot overflow a `u8`.

### EX-C041-04 — Keep validation active in release builds

**Intermediate.** A function calls `debug_assert!(requested <= remaining)`
before subtracting a customer request. Replace it with a normal
error path and give the two boundary cases to test.

### EX-C041-05 — Establish the sequence invariant

**Challenge.** Prove that after any sequence of requests, availability
equals the starting total minus the sum of successful requests.
Explain what a test over all initial `u8` pairs checks.

### Knowledge check

- **IQ-C041-01, beginner.** When should a failed lookup return `None`?
- **IQ-C041-02, intermediate.** What does a `debug_assert!` guard
  guarantee for callers of a release API?
