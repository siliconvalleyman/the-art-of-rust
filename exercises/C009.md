### EX-C009-01 — Count device pairs

**Beginner.** Implement the number of unordered pairs of
distinct devices from an unsigned 32-bit count. Return zero
for 0 and 1. Give results for 2 and 6, and explain why
dividing the count of ordered pairs by two is valid.
Check the largest supported count with widened arithmetic.

### EX-C009-02 — Count passing samples

**Intermediate.** A tester selects two different devices
uniformly from a set with a given count of good and faulty
devices. Return a pair consisting of the number of all-good
pairs and the total number of pairs, or absence if there
are fewer than two devices. Evaluate four good and two
faulty, zero good and two faulty, and a single good device.
Describe how replacement would change both counts.

### EX-C009-03 — Advance a circular index

**Intermediate.** Implement the modular ring update in the
chapter for unsigned 64-bit numbers. Reject capacity zero
and starting indices outside the ring. Test capacity one,
exactly reaching the end, and a capacity of the largest
64-bit value. Prove that all arithmetic intermediates fit.

### EX-C009-04 — Compute a whole-number GCD

**Intermediate.** Implement Euclid's algorithm over
nonnegative integers. Specify the result for two zeros.
Test `(84,30)`, `(30,84)`, `(0,17)`, and
`(1,n)` for a positive `n`. Use a simple exhaustive
divisor check as a test oracle on small inputs.

### EX-C009-05 — Derive a three-digit code space

**Challenge.** A code generator chooses a first nonzero
decimal digit and then two distinct digits different from
the first. Derive the number of distinct codes and write
pseudocode enumerating them in numeric order. Test that
`102` appears exactly once and `101` is rejected.
Explain why uniformity of generated codes would require
a sampling rule in addition to a count.
