### EX-C024-01 — Shorten a shared reference

**Beginner.** Return static text under the lifetime of
a borrowed unit marker. Test a caller with a local
marker. Explain which direction of substitution is
valid and why its reverse is invalid in general.

### EX-C024-02 — Separate the lifetimes of a slot

**Intermediate.** Write a function that changes the
reference in a mutable slot. Give different names
to the loan of the slot and the promise of the
stored reference. Show that this does not allow a
local reference to satisfy a static slot.

### EX-C024-03 — Reproduce and repair the invariant slot

**Intermediate.** Verify the fixture fails on Rust
1.75.0. Repair it once with a literal and once by
using a slot without the explicit static type.
Explain how the second repair constrains later use.

### EX-C024-04 — Substitute a consumer

**Intermediate.** Write a function that takes a
callback for a static string reference and invokes it
with `"fixed"`. Supply a callback that works for any
valid borrowed string. Explain the permitted direction
using the sets of callable inputs.

### EX-C024-05 — Find the missed mutability path

**Challenge.** Use two shared references to a cell
containing an integer. Update through one path and read
through the other. Explain what could go wrong if a
cell storing a longer-lived reference could be used
as a writable cell storing a shorter-lived one.

### Knowledge check

- **IQ-C024-01, beginner.** In `&'borrow mut &'data str`,
  which lifetime governs the loan and which describes
  the stored value?
- **IQ-C024-02, intermediate.** Why can reading-only
  positions and writable slots differ in their variance?
