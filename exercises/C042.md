### EX-C042-01 — Trace the first failure

**Beginner.** Classify the loader results for the strings `" 10 "`,
`""`, and the single byte `0xff`. Identify which stages ran.

### EX-C042-02 — Propagate an optional field

**Beginner.** Implement `first_nonzero` that accepts `Option<u16>` and
returns `None` for absence or zero, using `?` on the option.

### EX-C042-03 — Choose context at a conversion site

**Intermediate.** An operation creates a file and then writes a header.
Both operations return `io::Error`. Give a type and two distinct
conversion expressions that a caller can match.

### EX-C042-04 — Measure effects before early return

**Intermediate.** Write a function that parses two strings left to
right and increments a counter before parsing the second. Use `?`
and test first-field and second-field failures.

### EX-C042-05 — Design a bounded read contract

**Challenge.** The chapter loader assumes a finite, short source. Define
an algorithm that reads at most `B + 1` bytes for a fixed positive
byte limit `B`. Explain how it distinguishes an exact-limit input
from an oversized one and when it can still wait for I/O.
