### EX-C021-01 — Transfer one owner

**Beginner.** Make a heap-owned string with the text
`"ready"`, move it to a new binding, and return the
new binding from a function. Assert its contents at
the caller. Trace the owner before and after each move.

### EX-C021-02 — Repair use after move

**Beginner.** Reproduce E0382 from the fixture. Fix the
program in two ways: first using the new binding, then
preserving an independent owned string under the old
name. Explain which version allocates an extra string
buffer under the library contract.

### EX-C021-03 — Distinguish Copy from Clone

**Intermediate.** Demonstrate that assignment of a
`u32` leaves both names usable. Create two independent
owned strings by cloning one, edit just one, and verify
both outputs. Explain why the integer example does not
predict the cost of the string operation.

### EX-C021-04 — Track a partially moved tuple

**Intermediate.** Make an owning tuple `("room", "open")`
as two strings. Move out the first. Show that the second
can be read. Reinitialize the moved field, and verify the
whole value becomes usable with the new label. Name which
binding owns each string at the end.

### EX-C021-05 — Observe exactly one cleanup after transfer

**Challenge.** Define a guard that increments a small
observer when destroyed. Move the guard through one
function to a caller-owned binding. Verify the observer
stays zero across the handoff, then increases once before
the final check. Explain the limits of the result across
ordinary returns and abrupt process termination.
