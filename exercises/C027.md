### EX-C027-01 — Count and enumerate a sum

**Beginner.** Model a lamp as off or lit at one of
three levels. Encode the alternatives, enumerate their
outputs in off-then-level order, and explain which case
has a payload. Treat all three levels as distinct.

### EX-C027-02 — Map every route

**Beginner.** Send the same numeric code through a
locker, a fragile delivery, and a standard delivery.
Check three different results. Explain how the same
number can be reused across variants without losing its
meaning.

### EX-C027-03 — Destructure a borrowed payload

**Intermediate.** Model a queued job as empty or
having an owned description. Write a function that
returns a borrowed description only for the second
case. Test the empty case and show the caller can
still borrow the original job after the call.

### EX-C027-04 — Prove a guarded match is total

**Intermediate.** Classify a signed 8-bit input as
negative, zero, or positive using a guarded match
and an unguarded fallback. Test the minimum, zero,
and maximum. Prove what the fallback can contain.

### EX-C027-05 — Move a payload without a sentinel

**Challenge.** An input enum represents a message with
owned text or a deliberate stop. Return the owned text
as an optional value. Preserve an empty message as
distinct from stop. Verify both cases without cloning.

### Knowledge check

- **IQ-C027-01, beginner.** Why does counting the route
  values add alternatives rather than multiply them?
- **IQ-C027-02, intermediate.** Which property does
  exhaustiveness establish, and what can a test still
  reveal about an exhaustive match?
