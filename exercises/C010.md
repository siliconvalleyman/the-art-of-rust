### EX-C010-01 — Count a triangular loop

**Beginner.** A loop visits pairs of positions `i < j`
in a list of length `n`. Derive and implement its
count from a nonnegative input. Give the zero-length and
single-element results and prove a tight growth class.
Connect your implementation to the count from Chapter 9.

### EX-C010-02 — Count a search with repeated matches

**Intermediate.** Return the first matching index and the
comparison count. For input `[5, 0, 5]` and target 5
expect `(0, 1)`, or absence and three comparisons for
target 4. Check the empty list. Provide a loop invariant
and describe how testing presence alone could misclassify
a last-occurrence implementation.

### EX-C010-03 — Compute an expected count exactly

**Intermediate.** Suppose a nonempty search has a unique
uniformly distributed successful position and miss
probability `p/q` with integers `q > 0` and
`0 ≤ p ≤ q`. Return an exact numerator and denominator
for the expected number of comparisons. Use a type that
can hold intermediate results when `n`, `p`, and
`q` are unsigned 32-bit numbers. Check `n = 7`,
`p = 1`, `q = 4` and check invalid probability inputs.

### EX-C010-04 — Count array copies without simulating elements

**Intermediate.** Return total copies for `n` insertions
into the chapter's doubling array. Count only growth
copies. Check `n = 0, 1, 2, 4, 5, 9`. Give
pseudocode that visits only capacity growth events.
Show why its work is logarithmic in positive `n`.

### EX-C010-05 — Compare cumulative growth policies

**Challenge.** Change the model to grow capacity by one
slot when full. Derive the total copies for `n)
insertions and its asymptotic bound. Check `n = 5`
and compare it with doubling under the same counting
model. Explain which policy can reserve fewer unused
slots immediately after insertion.
