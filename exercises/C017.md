### EX-C017-01 — Return an owned measurement

**Beginner.** Write a function that creates and returns
a `Box<u64>` holding 17. Assert that the caller can read
17. Identify the owner before and after the return and
name when cleanup can occur.

### EX-C017-02 — Choose storage with a contract

**Intermediate.** Write a simple interface returning a
room capacity by value and a shared reference to a
fixed three-byte protocol marker. Use a constant for
120 and a static object for `LAB`. Explain why the
capacity requires no stable object identity.

### EX-C017-03 — Trace reverse declaration order

**Intermediate.** Using the marker example, declare
two markers in one inner block with digits 3 and 4.
Predict the trace after both leave scope and assert the
ordering. Explain why reading the trace before leaving
the block cannot show their cleanup.

### EX-C017-04 — Release a resource on ordinary early return

**Intermediate.** Write a function that creates a
guard with digit 1, returns early for a flag of
`true`, and returns normally with `false`. Test
that both paths perform cleanup once. Explain what the
experiment can establish about these two control paths.

### EX-C017-05 — Report a failed finalization

**Challenge.** Sketch a function for writing a record
through a resource owner. Its `finish` operation can
fail, and its destructor can only attempt best-effort
cleanup. Give an explicit result for success, an initial
write failure, and a finalization failure. State where
ownership is held on every path.

- **IQ-C017-02, intermediate.** Why should a program
