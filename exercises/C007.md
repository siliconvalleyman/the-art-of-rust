### EX-C007-01 — Find the remaining jobs

**Beginner.** Model jobs numbered 0 through 7 by a byte
with bit `i` indicating job `i`. Return the requested
jobs absent from the cache mask. For requested `00101100`
and cached `01100100` expect `00001000`. Test an empty
request and a cache containing every job. Show the membership
rule for one position.

### EX-C007-02 — Show why shared inputs fail equivalence

**Intermediate.** A job uses a nonempty set of input IDs.
Two jobs are related if their input sets overlap. Build the
full relation for jobs with sets `{1}`, `{1, 2}`, and
`{2}`. Explain symmetry and supply a transitivity
counterexample. Write a table-construction algorithm and
test that duplicate occurrences inside a set do not affect
the truth values.

### EX-C007-03 — Compose two prerequisite steps

**Intermediate.** Return whether a directed graph has a
walk of exactly two edges between two specified vertices.
Use the matrix query from the chapter and prove the
invariant. Test Figure 1, a three-vertex graph containing
only edge `0 → 2`, and a one-vertex graph with a self-edge.
Include an out-of-domain index.

### EX-C007-04 — Find a partial mapping collision

**Intermediate.** Given a list of assigned slots, one
entry per job, return the lexicographically first pair
of distinct job positions with the same slot. The first
element of the pair must be less than the second. For
`[7, 2, 2, 7]` expect `(0, 3)`. Empty input and
distinct slots return absence. Compare ordering by the
first element with ordering by the second.

### EX-C007-05 — Model an inverse

**Challenge.** A function from three jobs to three slots
is represented by an array of three numbers in 0 through
2 in job order. Return the inverse when it exists, or an
error. Test `[2, 0, 1]`, `[2, 0, 0]`, and
`[2, 0, 3]`. State how the tests check uniqueness,
coverage, and domain error handling.
