### EX-C012-01 — Trace a mutable counter

**Beginner.** Start with a `u16` count of 32. Add 6
and then 9 by updating the same binding. Return your
source and the value after every statement. Assert the
final value. State what happens if `mut` is removed.

### EX-C012-02 — Widen deliberately with shadowing

**Beginner.** Bind the value 250 as a byte. Shadow it
with a 16-bit expression adding 10. The final value
must be 260. Explain the type of each binding and why
widening after adding would be too late. Test the
expected type through an annotated binding or assertion.

### EX-C012-03 — Produce a block value

**Beginner.** Declare a constant seat limit of 100.
With two groups of 21 and 17 people, use a block to
calculate the remaining seats. Declare the occupied
count inside the block. Predict how a semicolon on
the final subtraction affects the type of the block.

### EX-C012-04 — Compare two scopes

**Intermediate.** Bind `status` to `"outer"`. In a
block, shadow it with `"sample"`, assert the inner
value, then assert the outer value after the block.
Explain whether either binding needed to be mutable.

### EX-C012-05 — Make arithmetic grouping explicit

**Intermediate.** Four identical trays each contain
two cups and three plates. Write expressions for the
total number of items and a comparison that checks
whether the total is at least 18. Use `u16` for
counts and assert the comparison result. Show how
`2 + 3 * 4` produces a different count.
