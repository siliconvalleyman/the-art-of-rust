### EX-C032-01 — Give a type an associated label

**Beginner.** Define a local trait with an associated
constant and a value method. Implement it for a record
holding a byte. Check the constant and the field value.
Explain which information belongs to the instance.

### EX-C032-02 — Reuse a default method

**Beginner.** Give a trait a required numerical method
and a default Boolean check for zero. Implement
only the numerical method for a record and verify the
Boolean check for zero and a nonzero value.

### EX-C032-03 — Bound the associated type

**Intermediate.** Define a second source implementing
Reading with associated unit Grams. Verify that the
chapter's aggregation accepts that source. Explain why
Volume cannot instantiate the same call.

### EX-C032-04 — Use a supertrait

**Intermediate.** Write a function requiring
BoundedReading that returns the amount and whether
it satisfies its limit. Test 30,000 and 30,001 for
the provided Weight implementation.

### EX-C032-05 — Prove overflow cannot be corrected

**Challenge.** Prove the aggregation's checked failure
agrees with its final nonnegative sum. Test a boundary
sum, an overflowing prefix, and empty input. Give
a signed counterexample showing why the same argument
would fail if later amounts could be negative.

### Knowledge check

- **IQ-C032-01, beginner.** What is the difference
  between an associated constant and a stored field?
- **IQ-C032-02, intermediate.** How does a supertrait
  constrain an implementation and what can a generic
  caller infer from that relationship?
