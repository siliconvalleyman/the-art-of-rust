### EX-C018-01 — Round up without overflowing early

**Intermediate.** For a `usize` offset and a positive
power-of-two alignment, return the smallest aligned
offset at least as large as the input, or absence if
that result cannot fit. Reject invalid alignments.
Test zero, offset 5 with alignment 4, and `usize::MAX`
with alignments 1 and 2.

### EX-C018-02 — Derive an alternative order

**Beginner.** Under the chapter's sizes and alignments,
use the declaration order `flags, tag, count` for the
`repr(C)` record. Write a procedure to place each
field, compute each offset and the final size, and
identify all padding.

### EX-C018-03 — Compare native and wire size

**Intermediate.** An array holds five instances of the
measured twelve-byte record. The same five records are
encoded in the chapter's seven-byte wire format. Compute
both byte totals and their difference. Derive a checked
size calculation for a nonnegative record count.

### EX-C018-04 — Decode a little-endian count field

**Intermediate.** Accept a byte slice of exactly four
bytes interpreted as little-endian `u32`. Reject every
other size. Test `[1,2,3,4]`, `[0,0,0,0]`, and three
bytes. Explain why `[1,2,3,4]` detects a reversed
byte-order implementation.

### EX-C018-05 — Reject unknown flags

**Challenge.** For the seven-byte record in the chapter,
accept only the flag bits with mask `0x0003`. Test
an exact record with flags 3, flags 4, and a truncated
record. Explain why interpreting the byte order must
precede the flag check.
