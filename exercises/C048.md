### EX-C048-01 — Choose exact membership or a value

**Beginner.** Model a set of package names awaiting review and a
separate map of approved versions. Verify that scheduling the same
name twice differs from replacing an approved version.

### EX-C048-02 — Apply the hash contract

**Beginner.** Two record values have the same account ID and different
labels. If equality uses only the ID, decide which fields the hash
may include. Explain what it means when two different IDs collide.

### EX-C048-03 — Count a fixed-occupancy query

**Intermediate.** A model Bloom filter has eight bits, three of
which are set. Two query positions are independent and uniform with
replacement. Count passing ordered pairs and derive the probability.
Explain how sampling without replacement changes it.

### EX-C048-04 — Show one false positive and one rejection

**Intermediate.** Insert fingerprint pairs `[10, 14]` and `[9, 12]`
in `Bloom64`. Give a new pair that passes and a pair that is ruled
out. Write assertions for both and verify that the original items
still pass.

### EX-C048-05 — Review an LRU policy

**Challenge.** With capacity two, insert `A` and `B`, replace `A`,
look up a missing key, and insert `C`. Verify the evicted pair and
prove why a miss leaves the next eviction unchanged. Explain how
a policy that counts only reads would change the trace.

### Knowledge check

- **IQ-C048-01, beginner.** Does equal hash output imply equal keys?
- **IQ-C048-02, advanced.** Why is the Bloom false-positive estimate
  conditioned on actual occupancy in the independent query model?
