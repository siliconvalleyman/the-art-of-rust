### EX-C026-01 — Count a finite product

**Beginner.** Model a printer with widths 20 and 40 mm
and heights 10, 30, and 50 mm. Generate all dimension
pairs in width-major order, with height increasing inside
each width. State the exact count and why no pair repeats.

### EX-C026-02 — Name two equally typed fields

**Beginner.** Define a struct with a received count and a
completed count, both `u32`. Implement a shared method
that returns the pending count, using absence when the
completed count exceeds the received count. Test zero,
an ordinary value, and an invalid snapshot.

### EX-C026-03 — Select a constructor and a receiver

**Intermediate.** Model a queue number with a tuple
struct. Add an associated constructor and a shared method
returning the next number, with absence when the increment
does not fit in `u16`. Test both the maximum and a normal
input. Explain why the method can use a shared receiver.

### EX-C026-04 — Prove field exchange

**Intermediate.** Use the chapter's `Dimensions` type
to verify that two rotations restore the input pair.
Include a nonsquare case. Give both the algebraic
argument and a test that would detect a method that
never exchanged the fields.

### EX-C026-05 — Consume or borrow an owned record

**Challenge.** Define a record containing an owned name
and a numerical identifier. Add one method that borrows
the name and a consuming method that returns the name.
Prove which call leaves the record available. Demonstrate
that the original String can be passed to the caller
without cloning.
