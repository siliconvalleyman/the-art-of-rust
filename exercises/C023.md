### EX-C023-01 — Expand an elided signature

**Beginner.** Write a function returning the first byte
reference of a `&str`, or absence. Produce an elided
and explicit signature, and show why they have the same
input-output relationship. Test an empty string and `"A"`.

### EX-C023-02 — Choose a source for a returned view

**Intermediate.** Write a function that returns its
second of two text inputs. Its output must be usable
after the first input's local owner ends, provided
the second remains valid. Show a caller with those
scopes and justify each annotation.

### EX-C023-03 — Require a common region

**Intermediate.** Make a selector that returns either
the first or second text argument based on a Boolean.
Both possibilities must obey the same return lifetime.
Test both choices. Explain why promising the output
lifetime of only the first input would be too strong.

### EX-C023-04 — Repair a return of local data

**Intermediate.** Reproduce the reference-to-local
diagnostic. Change the function to return ownership and
verify the caller can read the returned text. Identify
which destruction scope now controls the buffer.

### EX-C023-05 — Distinguish a static bound by observation

**Challenge.** Give an owned value to a generic
function with a static bound. Make it observable that
the value can be dropped during the call. Explain why
the observation cannot be derived from the lifetime
bound alone and how a static reference would differ.

### Knowledge check

- **IQ-C023-01, beginner.** What does an explicitly
  named output lifetime say when it is also named
  on two input references?
- **IQ-C023-02, intermediate.** Why can `String`
  satisfy a static bound while a borrow of a local
  String typically cannot?
