### EX-C019-01 — Measure total and contiguous capacity

**Beginner.** Given a Boolean slot map, return the
number of free slots and the length of the longest
contiguous free run. Test `[true,true,false,true]`,
an empty map, and an entirely occupied map. Explain
why a request for three slots fails on the first map.

### EX-C019-02 — Find the first sufficient run

**Intermediate.** Use the first-fit contract and write
a test for two separate runs that can satisfy a request
of length two. Check that the earlier run is chosen.
Test a run ending at the final index and derive a
termination measure.

### EX-C019-03 — Coalesce adjacent intervals

**Intermediate.** Given sorted, disjoint nonempty half-open
free ranges, merge adjacent ranges in order.
For `[0,4), [4,7), [9,11)`, return
`[0,7), [9,11)`. Explain why no free position changes.
Test a repeated adjacency chain and empty input.

### EX-C019-04 — Count misses under changing capacity

**Intermediate.** For the four by four array trace,
apply the specified least-recently-used model with three
cache slots, then with four. Report column-major misses
in each case. State which resident lines justify the
transition from one observation to the next.

### EX-C019-05 — Compare fixed size classes

**Challenge.** For requests of 3, 5, 8, and 9 slots,
allocate the smallest fitting class from 4, 8, and 16.
Report the reserved total and internal fragmentation.
Compare it with classes 4, 8, 12, and 16. Derive
a selection algorithm that rejects oversized and zero requests.

### Knowledge check

- **IQ-C019-01, beginner.** Why can total free storage
  exceed a request that still fails?
- **IQ-C019-02, intermediate.** What would you need
  to know before concluding that a modeled cache-miss
  reduction makes a real program faster?
