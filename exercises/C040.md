### EX-C040-01 — Test duplicate and threshold handling

**Beginner.** Select up to three values at least
7 from `[3, 7, 7, 5, 8]`. Verify order, duplicates,
an empty input, and a zero budget.

### EX-C040-02 — Detect the wrong adapter order

**Beginner.** Find a short input where applying
`take(2)` before an inclusive threshold filter
returns fewer results. Verify both versions and
explain the source of the difference.

### EX-C040-03 — Count actual predicate calls

**Intermediate.** Instrument the threshold predicate
for `[1, 8, 2, 7, 5, 9]`. Compare demanding two
eligible values with eagerly collecting all eligible
values. Give both observed call counts.

### EX-C040-04 — Compare with a reference model

**Intermediate.** Write an eager loop that selects in
order and truncates after collection. Compare it with the
chapter implementation for several budgets. Include duplicate
and absent matches.

### EX-C040-05 — Choose a return interface

**Challenge.** Change the requirement so a caller can
hold the selected values after the input is deleted.
Give a concrete API for that lifetime requirement
and compare the storage and work with returning the
chapter's borrowed iterator.

- **IQ-C040-02, intermediate.** When does a small
