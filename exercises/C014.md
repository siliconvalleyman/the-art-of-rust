### EX-C014-01 — Destructure one reading

**Beginner.** Store a `u16` count of 42 and a readiness
flag in one tuple. Use a pattern to bind both and check
their values. Explain why both fields cannot be accessed
by one unspecified numeric type.

### EX-C014-02 — Select a fixed window

**Beginner.** Given array `[4, 5, 6, 7]` of bytes,
use a half-open slice expression to select `[5, 6]`.
Assert the slice's length and use `get` to check
position 2 of the slice. Explain which array position is
excluded by the upper bound.

### EX-C014-03 — Count representation units

**Intermediate.** Compute byte length and scalar count
for `"e\u{301}"` and `"é"`. Show how bytes and
scalar values can both differ even when displayed text
may look alike. Use separate assertions for both units.

### EX-C014-04 — Validate a byte sequence before using it

**Intermediate.** Define a function that returns a
UTF-8 view only when every byte belongs to a valid
sequence. Test empty input, `[0xc3, 0xa9]`, and
`[0xc3]`. Explain whether a successful result owns
a copy of the bytes.

### EX-C014-05 — Preserve UTF-8 under a byte budget

**Challenge.** Derive a function that returns the longest
valid UTF-8 prefix of a string at a given byte limit.
For `"Aé🦀"`, test a limit before the first letter,
in the middle of each multibyte encoding, at the exact
length, and beyond it. Give the invariant that establishes
maximality and a small constant bound on loop iterations.

- **IQ-C014-02, intermediate.** A UI truncates a string
