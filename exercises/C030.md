### EX-C030-01 — Recover and retry

**Beginner.** Open dispatch 17, try preparing zero
parcels, and retry with one parcel after extracting the
returned draft. Assert the error and the preserved
identifier. Explain why returning only an error changes
the caller's recovery options.

### EX-C030-02 — Test an inclusive bound

**Beginner.** Verify that 500 parcels can produce a
ready value and 501 cannot. Identify the state and data
retained in each branch. Check that zero cannot pass in
an implementation with an upper bound alone.

### EX-C030-03 — Prove that an operation is unavailable

**Intermediate.** Run the chapter's compile-fail case
on Rust 1.75.0. Fix it by explicitly executing the legal
transition before recording shipment. Verify the receipt
and explain why an untyped helper that accepts both
states would need a separate check.

### EX-C030-04 — Store mixed states

**Intermediate.** Give an enum representation for a
collection that can hold draft and shipped dispatches.
Write an inspector that reports the identifier without
moving an entry. Test both variants and justify coverage.

### EX-C030-05 — Separate state from an external effect

**Challenge.** A carrier may reject a request or accept
it while its response is lost. Model the states of a
local workflow that must report those cases distinctly.
State what evidence permits recording success and explain
why a timeout is insufficient evidence of rejection.
