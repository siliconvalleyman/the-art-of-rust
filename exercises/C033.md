### EX-C033-01 — Extend an existing type locally

**Beginner.** Define a local trait providing a
Boolean check that a byte slice is empty. Implement
it for `[u8]` and test empty and nonempty slices.
Explain which participant makes this eligible.

### EX-C033-02 — Format a local wrapper

**Beginner.** Create a local wrapper of `u8` whose
standard Display output includes the prefix `bay-`.
Verify the wrapped and unwrapped output differ.
Identify what a type alias would change.

### EX-C033-03 — Exhibit an overlapping type

**Intermediate.** Given a local trait with a blanket
implementation for all Debug types, determine whether
a second implementation for `u8` is allowed. Give
a concrete overlap witness and one way to separate
the two behaviors.

### EX-C033-04 — Implement a blanket rule

**Intermediate.** Introduce a local trait with a
method that returns the Display text in brackets.
Implement it for all default-Sized Display types.
Test two different types and explain the capability
that justifies applying it to both.

### EX-C033-05 — Separate competing policies

**Challenge.** Two operations render a parcel ID
for a customer and for a log. They need different
text. Build two local wrapper types that use Display
for the two policies. Demonstrate both and explain
why one shared implementation would not encode the
caller-selected policy.

### Knowledge check

- **IQ-C033-01, beginner.** How does an orphan
  implementation differ from an overlapping one?
- **IQ-C033-02, intermediate.** What should you
  examine before adding a blanket implementation
  to a public trait?
