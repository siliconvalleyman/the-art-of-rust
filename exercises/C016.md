### EX-C016-01 — Derive the array offset

**Beginner.** In a byte-addressed model, a four-element
`u32` array starts at address `0x2000`. Derive an
algorithm that returns the start of an element or rejects
a requested index outside the array. Test indices 0, 3,
and 4. State the last occupied byte.

### EX-C016-02 — Compare the distance of two raw pointers

**Intermediate.** In safe Rust, obtain pointers to the first
and third elements of a three-element `u16` array. Check
that their numerical address difference is four. Explain which
object supplies both addresses and why the test needs no
literal address.

### EX-C016-03 — Trace a nested call

**Beginner.** Suppose `main` calls `measure`, which
calls `calibrate`, which returns to `measure`.
Then `measure` calls `read` and returns after `read`.
List the active calls at their maximum logical depth and
give one table for both positions at that depth. Explain
why `calibrate` and `read` do not coexist in this trace.

### EX-C016-04 — Read the Windows x64 leaf

**Intermediate.** Under the chapter's target and compiler
flags, reproduce the assembly capture. Trace the ABI
registers for `(0, 0)`, `(12, 50)`, and
`(u64::MAX, 1)`. Explain how you can tell whether the
shown body reserves stack storage or reads the computed
address as data.

### EX-C016-05 — Avoid overflowing offsets

**Challenge.** Implement a function taking `index`,
`len`, and `width`, all `usize`. Return an offset
only when `index < len`, `width > 0`, and
`index × width` fits. It computes an offset only.
Test a valid interior position, an out-of-range index,
zero width, and an overflowing product.
