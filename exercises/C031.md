### EX-C031-01 — Select an element without copying

**Beginner.** Implement a generic function that
returns an optional shared reference to the second
element of a slice. Test lengths zero, one, and two.
Explain what lets the body work for a type without Copy.

### EX-C031-02 — Explain inference from an empty input

**Beginner.** Call the chapter's endpoint selector on
an empty array literal, using an explicit element type.
Then call it on an array of two characters without
an explicit argument. Explain what each call supplies.

### EX-C031-03 — Move independent values

**Intermediate.** Reverse a generic pair whose first
field is a String and whose second is a Boolean.
Use annotations to verify the result type. Explain how
returning `Pair<A, B>` would change what was promised.

### EX-C031-04 — Require equal lengths

**Intermediate.** Write a function receiving borrowed
arrays of arbitrary element types, both with the same
const length. Return that length. Test zero and three
and explain what happens when callers supply different
lengths.

### EX-C031-05 — Audit an accidental bound

**Challenge.** Someone creates a generic helper that
returns the first two entries by reference but clones
them first. Give a helper that needs no Clone bound.
State a test type and reason about how the output
borrows and cannot outlive the slice.

### Knowledge check

- **IQ-C031-01, beginner.** Why is a function body
  checked against its generic signature even if the
  only caller today passes an integer?
- **IQ-C031-02, intermediate.** What does writing
  `Pair<T, T>` require that `Pair<A, B>` does not?
