### EX-C008-01 — Sum first integers at full width

**Beginner.** Implement the sum of 1 through an unsigned
32-bit input in an unsigned 64-bit result. Give the inductive
step and prove that the intermediate product fits. Test 0,
1, 100, and the largest 32-bit input. Explain how widening
after addition can invalidate the proof.

### EX-C008-02 — Construct a postage representation

**Intermediate.** Given a nonnegative 32-bit amount, return
two counts for denominations 3 and 5, or report absence.
For 0 return zero counts. Give a complete rule for amounts
below 8 and derive a rule for larger inputs from the strong
induction argument. Check 4, 7, 8, 9, 10, and 20.

### EX-C008-03 — Derive leaf counts

**Intermediate.** Write pseudocode that returns both leaf
and internal node counts for the chapter's trees. Prove the
leaf identity by structural induction. Trace a tree with a
leaf on the left and a node with two leaf children on the
right. Give a shape that would refute the identity if
unary nodes were permitted.

### EX-C008-04 — Verify a balanced-work predictor

**Challenge.** Implement the recurrence as a bounded test
oracle and compare it against the closed form for
`n = 0` through `n = 128`. Explain why the oracle
uses separate floor and ceiling sizes. Test `n = 7`
and `n = 8` explicitly. Describe the error produced by
rounding both halves down.

### EX-C008-05 — Count decimal digits by division

**Intermediate.** Return the number of base-ten digits of a
32-bit nonnegative integer. Give the output 1 for zero.
For positive inputs use repeated division by 10 and prove
termination. Test 0, 9, 10, 99, 100, and the maximum input.
Relate the number of divisions to the output count.

### Knowledge check

- **IQ-C008-01, beginner.** Why does proving the induction
  step fail to establish a statement when the base case is
  false?
- **IQ-C008-02, intermediate.** What is the cost of assuming
  both halves contain `n/2` items when deriving a recurrence
  for an odd integer size?
