### EX-C035-01 — Mark two units

**Beginner.** Use the Quantity wrapper with two unit
markers and the same number. Test equal numeric
payloads and compare their represented sizes. Explain
what the matching sizes tell you about allowed calls.

### EX-C035-02 — Accept a fresh borrow for each call

**Intermediate.** Call the provided inspector with
a function counting ASCII letters. Verify the results
for the two internal strings. Explain why a callback
requiring `&'static str` would not meet the bound.

### EX-C035-03 — Derive the number of windows

**Intermediate.** Compute the number of successful
calls for lengths zero and four with width two, and
for length four with widths one and four. Test each
case and derive the inclusive last starting position.

### EX-C035-04 — Repair a conflicting window borrow

**Intermediate.** Reproduce E0499 from the
compile-fail fixture. Keep both writes in the original
order but let the first borrow end before requesting
the second. Verify the final byte array.

### EX-C035-05 — Separate callback output from its input

**Challenge.** Define a helper that supplies a
short-lived string to a callback that returns an owned
String. Verify the returned value is usable after
the helper returns. Contrast the result with a
callback returning a borrow tied to the supplied input.

### Knowledge check

- **IQ-C035-01, beginner.** How can two quantities

- **IQ-C035-02, intermediate.** Why does the window
  interface tie an item to the specific borrow of its
  receiver?
