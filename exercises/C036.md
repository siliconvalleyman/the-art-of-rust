### EX-C036-01 — Evaluate the independent functions

**Beginner.** Compute subtotal, discount, and quote for
zero, one, and three items. Verify the compiled functions
and explain which intermediate calculation uses rounding.

### EX-C036-02 — Pass the policy as an input

**Beginner.** Write a pure function that takes a
count and a rate, both `u16`, and returns the subtotal
in a sufficiently wide type. Test the maximum values.
Explain why reading the rate from a global variable
would change what the input contract describes.

### EX-C036-03 — Distinguish two compositions

**Intermediate.** Compare rounding a ten percent
discount on a subtotal with discounting an item count
first and then multiplying. Produce an input where
they differ and justify the two outputs.

### EX-C036-04 — Separate rendering from writing

**Intermediate.** Design an output function that takes a
count and a mutable writer and returns a write result.
Reuse creation of the receipt. Test a memory-backed writer
and state what a failed write test would still need.

### EX-C036-05 — Make the observation boundary explicit

**Challenge.** A proposed quote first increments a
global request counter. State why replacing the call
with its returned price can change a later observation.
Divide the operation into an effectful boundary and a
tested numeric function.

### Knowledge check

- **IQ-C036-01, beginner.** Does a signature returning
  a number establish that an operation performs no effects?
- **IQ-C036-02, intermediate.** What makes an
  equivalence argument for pure functions depend on
  the chosen observables?
