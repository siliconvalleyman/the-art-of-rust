### EX-C001-01 — Print in reverse

**Beginner.** Preserve two distinct input values across register
writes. Write a machine program that reads exactly two available bytes
and writes them in reverse order. A stream `[6, 9, 42]` should leave
42 unread and produce `[9, 6]`. With one available byte it should
fail before a write. Use at most one memory cell. For full credit,
give both a trace and a general argument. First ask what the second
`READ` destroys.

### EX-C001-02 — Count the copies

**Beginner.** Preserve the input position in a trace. Write a program
that consumes one byte and writes it three times, using no data cells.
For `[7, 8]`, the output is `[7, 7, 7]` and one byte remains.
For empty input the read fails. Explain why copying to output leaves
the register available for the following step.

### EX-C001-03 — Choose a path with the input

**Beginner.** Test both branch directions. Read a flag byte and one data
byte. With a zero flag, write the data byte. With a nonzero flag,
write twice the data byte using the machine's wrapped addition. The
inputs `[0, 128]` and `[1, 128]` should give `[128]` and
`[0]`. A missing data byte fails before output. Give a program
and trace both paths. Use the zero in an untouched cell when you need
a jump that the proposed instruction set always takes.

### EX-C001-04 — Expand the test domain

**Beginner.** Make failure handling part of a program's contract.
Adapt the room monitor for an interface that must process two
consecutive pairs using one cell. It should output a wrapped sum for
each complete pair. For `[10, 21, 0, 255]`, expect `[31, 255]`.
For `[10, 21, 0]`, expect the first output and a missing-input error.
Give a program and justify the state left by each read and write.

### EX-C001-05 — Bound a looping machine

**Challenge.** Specify a runner that accepts a program, an input stream,
and a nonnegative instruction budget. It must either return the halt
output, or return an execution or budget error while retaining written
bytes. Count a halting instruction toward the budget. A missing or
invalid instruction may be discovered only when trying to execute a
step. For a budget of zero, even a first-row halt must yield a budget
error. Provide pseudocode and establish the bound. Test a self-jump
and a one-row halt.

### Knowledge check

- **IQ-C001-01, beginner.** Two runs have the same `PC` and
  `A` but produce different values on the next step. Which
  additional state could account for that behavior?
- **IQ-C001-02, intermediate.** Give a case where the monitor's
  instruction trace is correct and the program fails its contract.
  Which assumption would you revisit first?
