### EX-C003-01 — Select exactly the intended alarm rows

**Beginner.** Derive a logic signal that turns on if either of
two sensors reports a fault, unless a maintenance bit is 1.
Give all eight rows and a gate expression. Both sensors reporting
a fault together must turn on the signal when maintenance is 0.
First derive the fault signal without the maintenance bit.

### EX-C003-02 — Build a selector with NAND

**Intermediate.** Implement the two-input selector from the
chapter using only two-input NAND gates. The selector's output
must be `old` when enable is 0 and `new` otherwise. Prove
the formula for both selector values. Include input pairs
`(0, 1)` and `(1, 0)` in the trace.

### EX-C003-03 — Verify a full adder by enumeration

**Intermediate.** Implement the full-adder gate equations in
pseudocode and verify all eight inputs against integer addition.
The check must reconstruct an integer from the two output bits.
Explain how tests would detect reversing the outputs for
`a = 1`, `b = 0`, `c = 0`.

### EX-C003-04 — Swap two registers at an edge

**Intermediate.** Model a synchronous step which swaps two bits
when an enable bit is high, and retains them otherwise. Write
pseudocode that returns both next values, and show a trace from
state `(0, 1)` for enable inputs 1, 0, and 1. Prove the
property that two enabled updates restore the original state.

### EX-C003-05 — Reduce a zero detector

**Challenge.** Define a circuit that is high exactly when
every bit of an eight-bit input is zero. Use only two-input OR
gates and one NOT. Build a balanced OR tree, count gates and
layers, and compare its depth with a serial OR chain. Test
inputs with a single 1 in the first or last position.
