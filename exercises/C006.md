### EX-C006-01 — Separate safety from completeness

**Beginner.** A filter accepts a byte when it is at most 10.
The specification allows every even byte at most 10 and
rejects all others. Define two predicates, write both implication
directions, and implement the intended filter in pseudocode.
Give a counterexample for any implication the existing filter
violates. Include 0, 10, and 11 in the test plan.

### EX-C006-02 — Guard a configurable limit

**Intermediate.** For unsigned bytes `a`, `b`, and
`limit`, return `a + b` when the ordinary sum is at most
`limit`, or report failure. Derive a guard that uses
only byte operations and never subtracts a larger number from
a smaller one. Prove both directions and test `(2, 3, 5)`,
`(0, 8, 7)`, and `(255, 1, 255)`.

### EX-C006-03 — Search for a witness

**Intermediate.** Accept a finite ordered list of byte totals
and return the index of the first value above a byte limit.
Return an explicit absence when none exists. The list
`[3, 2, 6, 9]` with limit 5 returns index 2.
State the universal claim that absence establishes, and
justify why no earlier returned index can be missing.
Include empty input and duplicated violations.

### EX-C006-04 — Check a shared calibration input

**Intermediate.** Given a finite table whose rows are inputs
and columns are monitors, return whether one input passes
every monitor. Decide what happens when no inputs exist
and when no monitors exist. Write both the specification and
the alternate quantifier order. Test Figure 1 and a table
with one all-pass row. For full credit describe how to
detect an irregular row length.

### EX-C006-05 — Negate a guarded claim

**Challenge.** A device reports that every accepted record
has a matching timestamp. Model an ordered stream of records
each with an acceptance flag and a timestamp-match flag.
Write the negation of the report and pseudocode returning
the first record that disproves it, if one exists.
Test one rejected, mismatching record and one accepted,
mismatching record. Explain why a mismatching timestamp
alone is insufficient.
