### EX-C015-01 — Handle the threshold exactly

**Beginner.** Given a package size and limit as `u16`,
return `"inspect"` when the size is larger and
`"regular"` otherwise. Compare 9, 10, and 11 with
limit 10. Explain the equality case.

### EX-C015-02 — Count all qualifying sizes

**Beginner.** Return the number of elements in a slice
strictly larger than a supplied limit. For `[4,12,10,15]`
and limit 10 return 2. Test empty input, all equal values,
and two equal qualifying values. State the loop invariant.

### EX-C015-03 — Report the first crossing

**Intermediate.** Return the first index whose size
exceeds a limit, or absence. For `[12,9,13]` and
limit 10, return index 0. Explain why scanning from the
end needs additional work to report the first index.

### EX-C015-04 — Guard a remainder

**Intermediate.** Write a Boolean function returning true
when a nonzero divisor divides a total exactly. Return
false for divisor zero. Use short-circuiting and test
`(10,0)`, `(10,5)`, `(10,3)`, and `(0,5)`.
Explain why every evaluated remainder is well defined.

### EX-C015-05 — Compare recursive and iterative checks

**Challenge.** Compare the chapter's recursive universal
check with an iterative one under the same input contract.
Include empty input and a failure near the beginning.
State and prove the iterative invariant, and derive
worst-case auxiliary space for both versions.
