### EX-C044-01 — Predict an unwind outcome

**Beginner.** An unwind-enabled executable publishes score 4, then a
worker panics with a static string before returning score 9. State
the reported outcome and published score.

### EX-C044-02 — Predict an abort outcome

**Beginner.** Apply the same example with `panic = "abort"` on a target
that supports the setting. Explain whether the function can return
and whether stack-unwinding destructors run.

### EX-C044-03 — Keep effects on one side of the catch

**Intermediate.** A worker must compute two numbers that will be
published together. Give an API that accepts a worker and retains
the previous pair if that worker fails before returning. Use ordinary
`Result` for the expected worker failure.

### EX-C044-04 — Diagnose an unwind-safety failure

**Intermediate.** Explain why a closure capturing `&mut Vec<u8>` that
pushes before panicking does not satisfy `UnwindSafe` by default.
Show a redesign that keeps the prior vector untouched on panic.

### EX-C044-05 — Choose an unfamiliar payload policy

**Challenge.** Give a reason an arbitrary panic payload can be
dangerous to drop at the boundary. Explain the outcomes of forwarding
it by `resume_unwind` and of handling only a known payload type.

### Knowledge check

- **IQ-C044-01, beginner.** What happens to an ordinary stack-local
  guard during unwinding?
- **IQ-C044-02, advanced.** Which guarantees are added by
  `AssertUnwindSafe` and which remain the programmer's responsibility?
