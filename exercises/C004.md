### EX-C004-01 — Separate address and value

**Beginner.** Trace the chapter's RV32I fragment with `x4 =
0x1000` and inputs 15 and 17. State the two load addresses,
the value of `x7`, the next PC after the branch, and the
final bytes at the store address. Repeat with both inputs zero
and destination initially all `ff`. Explain whether that
initial destination changes on each path.

### EX-C004-02 — Encode an instruction by fields

**Intermediate.** Use the demonstrated format for
`add x3, x1, x2`. Return the 32-bit word and its four bytes
in little-endian order. Decode the source and destination fields
to verify the result. Compare the encoding with the one that
swaps the sources. The destination should stay the same.

### EX-C004-03 — Implement a cache trace

**Intermediate.** Simulate the two-slot cache with four-byte
lines. Accept a finite sequence of nonnegative addresses.
Return the hit/miss decisions in access order. Test empty
input and `[0, 3, 4, 7, 8, 0]`. Use a representation
with an explicit empty state so that line 0 can miss on the
first access. Justify the update to a slot on either outcome.

### EX-C004-04 — Predict exact misses

**Intermediate.** Write pseudocode for the number of misses
in a cold-cache access sequence at consecutive bytes from 0.
Accept the nonnegative length `n`. Return 0 for `n = 0`,
1 for `n = 4`, and 2 for `n = 5`. Derive a formula that
can be implemented without adding 3 to a bounded input.

### EX-C004-05 — Find a conflict pair

**Challenge.** Derive the first positive line-aligned byte
address that evicts line 0 from the specified cache. Build a
length-six access sequence alternating that address and 0.
Prove all six accesses miss from a cold cache. Then find an
alternate positive line-aligned address for which the sequence
has exactly two misses. Explain the role of the slot index.
