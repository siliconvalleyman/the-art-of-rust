### EX-C020-01 — Report a checked range of pages

**Beginner.** With page size 16, find the covered pages
for start 15 and lengths 0, 1, and 2. Write the
algorithm using the last included address and show
which example crosses a boundary.

### EX-C020-02 — Distinguish empty and overflowing ranges

**Intermediate.** Implement a checked last-address
function for `u64` start and length. Return absence
for empty ranges and a different failure for overflow.
Test the greatest address with lengths 0, 1, and 2.
Explain why checking an exclusive endpoint produces the
wrong decision for one of those cases.

### EX-C020-03 — Check a span's permissions

**Intermediate.** Apply the table in Figure 1 to requests
for bytes 14 through 17 and bytes 32 through 33 as reads
and as writes. Implement a pseudocode guard that checks
all covered pages for the requested permission. Explain
why a permitted nonresident read can still require work.

### EX-C020-04 — Count faults at two capacities

**Intermediate.** Run an initially empty least-recently-used
page model on `[0,1,2,0,1,2,0,1,2]`. Count faults
with capacities two and three. Identify a per-step
invariant that proves each repeating pattern.

### EX-C020-05 — Set both a byte and page limit

**Challenge.** A service allows at most 16 requested bytes
and at most one touched page when pages are 16 bytes.
Write pseudocode that combines the two limits. Test
`start 14, length 2`, `start 14, length 3`,
`start 16, length 17`, and an empty request.
Accept empty requests only with valid configuration.
