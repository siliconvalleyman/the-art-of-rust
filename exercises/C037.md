### EX-C037-01 — Borrow a lookup table

**Beginner.** Use the sample helper with a closure
that reads an external array. Verify both outputs and
use the original array afterward. Identify which data
is captured and which data is passed on each call.

### EX-C037-02 — Accumulate with a mutable capture

**Beginner.** Use a visitor to count items greater
than five in `[5, 6, 8, 4]`. Test the result and
then empty input. Explain why equality does not count.

### EX-C037-03 — Preserve repeated calls after move capture

**Intermediate.** Move an owned String into a
closure returning only its length. Invoke the closure
twice, compare the outputs, and explain why the
original name is unavailable.

### EX-C037-04 — Return the captured owner

**Intermediate.** Use the single-call helper to
return an owned String captured by a closure. Verify
the result. Explain why a helper requiring Fn would
reject a callback that returns its captured String.

### EX-C037-05 — Observe an effect through Fn

**Challenge.** Pass a closure satisfying Fn to a
function that calls it twice. Have the closure update
a shared Cell on each call. Verify the two observable
counts and explain why an Fn constraint alone does
not guarantee purity.

### Knowledge check

- **IQ-C037-01, beginner.** Why can a move closure
  still implement Fn?
- **IQ-C037-02, intermediate.** Which bound supports
  invoking a callback repeatedly when it may mutate
  its captured environment?
