### EX-C028-01 — Preserve a legitimate zero

**Beginner.** Read the first element of a byte slice as
an optional value. Test an empty slice, a single zero,
and a two-element slice. Explain why using zero as a
sentinel would lose information.

### EX-C028-02 — Keep absent and malformed input apart

**Beginner.** Classify missing scanner text, an empty
supplied field, and `"000"`. Write three assertions and
identify the type variant on each path.

### EX-C028-03 — Derive the decimal conversion invariant

**Intermediate.** Starting from zero, update a measured
prefix by multiplying by ten and adding the next digit.
Trace `"203"`, prove that the greatest permitted prefix
fits in `u16`, and show why `"256"` is invalid as a byte.

### EX-C028-04 — Test error precedence

**Intermediate.** Find a supplied field that violates the
byte limit and the digit rule. Test its error. Give
another malformed field that reaches syntax checking
because it fits within the byte limit.

### EX-C028-05 — Propagate only actual errors

**Challenge.** Parse two optional fields. Return the sum
as an optional `u16` only when both are present. Return
the first parser failure in input order, even if the other
field is absent. Verify a sum of zero and 255, a missing
input, and malformed input following absence.

### Knowledge check

- **IQ-C028-01, beginner.** Why can a successful result
  still contain absence?
- **IQ-C028-02, intermediate.** Why can a parser's
  validation order be part of its public contract?
