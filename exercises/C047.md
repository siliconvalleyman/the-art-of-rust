### EX-C047-01 — Trace the new head

**Beginner.** Push `oak`, `ash`, and `elm` at the front of an empty
list. Pop one value and give the next iteration sequence. Verify it
without cloning from the list.

### EX-C047-02 — Add a shared front query

**Intermediate.** Add a `front(&self) -> Option<&T>` method to the
chapter list. Verify one value and an empty list. Explain why a
caller cannot use an outstanding front reference after `pop_front`.

### EX-C047-03 — Append through empty states

**Beginner.** Append a two-item `LinkedList` to an empty one, then
append the now-empty source again. Verify both lists and explain
which link joins are unnecessary in each call.

### EX-C047-04 — Reconstruct a wrapped traversal

**Intermediate.** A ring has capacity 8, front index 6, and length 5.
List its physical visit order and give the lengths of the two spans.
Derive a formula for any valid nonempty ring.

### EX-C047-05 — Repair a doubly linked removal

**Challenge.** A doubly linked sequence stores `A, B, C, D`. Give
the link edits to remove `B`, followed by `D`, then the current head
until empty. State what remains after each step and identify the
invariant broken by updating only the forward link in the first step.
