### EX-C011-01 — Print two exact lines

**Absolute beginner.** Build an executable with two printing
statements. It must print `Workshop open.` on the first
line and `Check in here.` on the second. Both lines end
with a newline. Give the source and explain the order in
which the statements run. The program takes no user input.

### EX-C011-02 — Preserve punctuation in a literal

**Absolute beginner.** Write a program that prints the
single line `Ready! (local)`. Identify the exclamation
marks and parentheses that the compiler reads as syntax,
and the ones that belong to the text sent to output.
Check the displayed line by running from a terminal.

### EX-C011-03 — Repair the macro invocation

**Beginner.** Start with the compile-fail program in the
chapter and make the minimum edit that produces the expected
line. Record `rustc --version` and identify the location of
the compile-time problem. Verify that the fixed result
includes the original exclamation mark inside the string.

### EX-C011-04 — Reproduce the output through Cargo

**Beginner.** Create a standalone Rust 2021 binary package
called `workshop-note` with no dependencies. Its program
produces the line `Bring a notebook.`. Identify the manifest
entry that selects the edition. Build and run it using the
reference toolchain. Give the successful command and result.

### EX-C011-05 — Distinguish build and run evidence

**Beginner.** Build a program that writes `sample A`.
Change the source so it writes `sample B`, save it, and
run the old compiler-produced executable before rebuilding.
Predict both observations, before and after a successful
build. Specify a verification routine that would detect
accidental execution of a stale file.

### Knowledge check

- **IQ-C011-01, beginner.** A package uses edition 2021

  numbers make?
- **IQ-C011-02, beginner.** A build succeeds and the binary
  exits successfully, but its one printed word differs in
  capitalization from the specification. Which result would
  a test need to observe to discover that mismatch?
