### EX-C045-01 — Apply a valid batch

**Beginner.** Start with five units and apply `"1\r\n4\r\n"`.
Give the number of rows and the published state. Repeat with the
empty string.

### EX-C045-02 — Predict competing failures

**Beginner.** From an inventory of five, apply `"1\ncat\n0\n0\n0"`,
then `"1\n0\n0\n0\ncat"`. Give each error and its precedence.

### EX-C045-03 — Test encoded length

**Intermediate.** Explain why 33 copies of `é` violate the byte limit
before parsing. Contrast 32 copies and predict the result without a
character count in the implementation.

### EX-C045-04 — Show rollback for a later error

**Intermediate.** Construct a test that starts with stock already
partly reserved, stages a valid line, and fails later from shortage.
Verify the line number, the staged balance in the error, and the
original inventory after the call.

### EX-C045-05 — Specify safe retries

**Challenge.** A process publishes a batch successfully and loses the
response. Explain why replaying the same input can change the stock.
Design a request-identity rule and state which information must be
recorded atomically with a successful update.
