### EX-C034-01 — Compare two call paths

**Beginner.** Apply Offset(4) to 8 using a generic
call and a borrowed trait object. Test that both
produce 12. Describe which values are borrowed and
whether an allocation is necessary for the view.

### EX-C034-02 — Prove that adjustment order matters

**Beginner.** Start at 5. Apply offset 2 then scale 4
and reverse the two operations. Check both results.
Use the original input when checking the reversed
order.

### EX-C034-03 — Classify an operation that returns Self

**Intermediate.** Compile the chapter's Duplicate
fixture. Give one repair that leaves duplication
available only when the concrete type is known.
Show an object still calling a second shared method.

### EX-C034-04 — Compose a mixed list without cloning

**Intermediate.** Construct two adjustment values.
Borrow the same offset twice in a list, with a scale
in between. Test the result and justify how shared
borrowing permits both views.

### EX-C034-05 — Compare what a build can establish

**Challenge.** Identify one cost property that can be
checked from emitted assembly and one that needs a
runtime workload. Specify target, compiler settings,
and data distribution for an experiment comparing
homogeneous and mixed adjustment families.
