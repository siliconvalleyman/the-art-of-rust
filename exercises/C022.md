### EX-C022-01 — Measure without taking ownership

**Beginner.** Write a function that measures the byte
length of a shared text view. Call it for an owned
string containing `"é"`, then use that string again.
Explain why the result is two and which name remains
responsible for cleanup.

### EX-C022-02 — End one borrow before writing

**Beginner.** Use a shared reference to check that an
integer begins at 4. Then borrow it mutably, store 8,
and check the final value. Show a rearrangement rejected
by Rust and identify the use of the shared reference
that keeps its borrow active.

### EX-C022-03 — Modify one value through two short calls

**Intermediate.** Given `&mut u16`, use two successive
reborrows to add 2 and 3 to a value initially 10.
Assert that the caller observes 15. Explain when each
borrow ends and state the arithmetic precondition.

### EX-C022-04 — Split and check the boundary

**Intermediate.** Provide two mutable views of a
slice at a checked split position. Test the empty
left view, empty right view, and one invalid position.
Prove that both views together cover exactly the original
positions and that no position belongs to both.

### EX-C022-05 — Update two distinct positions

**Challenge.** Given a mutable byte slice and two
distinct indices, write different values at those
positions using two mutable references returned by
one helper. Accept either index order. Reject equal
or out-of-range indices. Verify that index order
corresponds to the requested order of the returned
references.

### Knowledge check

- **IQ-C022-01, beginner.** Why can a shared borrow
  sometimes end before the block containing its name?
- **IQ-C022-02, intermediate.** Why might the compiler
  reject two indexed mutable references while a method
  such as `split_at_mut` can safely return two mutable slices?
