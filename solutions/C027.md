## Chapter 027

### EX-C027-01 — Count and enumerate a sum

```rust,edition2021
#[derive(PartialEq, Eq, Debug)]
enum Level { Low, Medium, High }

#[derive(PartialEq, Eq, Debug)]
enum Lamp { Off, Lit(Level) }

let states = [Lamp::Off, Lamp::Lit(Level::Low), Lamp::Lit(Level::Medium), Lamp::Lit(Level::High)];
assert_eq!(states.len(), 1 + 3);
assert_eq!(states[3], Lamp::Lit(Level::High));
```

Off is one unit case. The lit variant carries exactly
one of the three levels, so it adds three values.
An independent off flag and level would admit redundant
combinations such as an off lamp at level High.

### EX-C027-02 — Map every route

```rust,edition2021

assert_eq!(Route::Locker(7).desk(), Desk::Locker(7));
assert_eq!(Route::Deliver { zone: 7, fragile: true }.desk(), Desk::Padded(7));

```

The tag and flag determine the output case. Copying the

A mapping that used only the numeric code would be unable
to distinguish the three inputs.

### EX-C027-03 — Destructure a borrowed payload

```rust,edition2021
enum Job { Empty, Pending(String) }

fn description(job: &Job) -> Option<&str> {
    match job {
        Job::Empty => None,
        Job::Pending(name) => Some(name),
    }
}

let job = Job::Pending(String::from("inspect"));
assert_eq!(description(&Job::Empty), None);
assert_eq!(description(&job), Some("inspect"));
assert_eq!(description(&job), Some("inspect"));
```

The input borrow determines the lifetime of the output
view. The helper moves no String from the caller.
Trying to return an independent owned String through
that shared reference would require duplication or a
different input contract.

### EX-C027-04 — Prove a guarded match is total

```rust,edition2021
fn sign(value: i8) -> &'static str {
    match value {
        0 => "zero",
        n if n < 0 => "negative",
        _ => "positive",
    }
}

assert_eq!(sign(i8::MIN), "negative");
assert_eq!(sign(0), "zero");
assert_eq!(sign(i8::MAX), "positive");
```

Every integer is negative, zero, or positive. The first
arm handles zero and the second handles every negative
number. The unguarded fallback thus receives only positive
numbers. A guarded positive arm without a final unguarded
case would leave the compiler's coverage check unsatisfied.

### EX-C027-05 — Move a payload without a sentinel

```rust,edition2021
enum Command { Message(String), Stop }

fn into_message(command: Command) -> Option<String> {
    match command {
        Command::Message(text) => Some(text),
        Command::Stop => None,
    }
}

assert_eq!(into_message(Command::Message(String::new())), Some(String::new()));
assert_eq!(into_message(Command::Stop), None);
```

Moving `text` keeps its ownership in the result,
including when the message is empty. The tag records
whether the message existed. Using empty text to signal
stop would collapse two distinct inputs.

### Interview answers for Chapter 027

**IQ-C027-01.** A parcel chooses one variant. The
variant tag separates its values from every other
variant. Counting independently selectable fields
within a variant can still use a product.

**IQ-C027-02.** Every input must be covered.
A test can show that an arm maps a covered input to
the wrong action or mishandles its payload.
