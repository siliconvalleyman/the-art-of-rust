## Chapter 038

### EX-C038-01 — Trace exhaustion

The first call changes 2 to 1 and returns Some(2).
The second changes 1 to 0 and returns Some(1).
The next two calls return None and leave the field
at zero. Confusing the sentinel state with an item
would append a spurious zero.

### EX-C038-02 — Check the exact size hint

```rust,edition2021
{{#include ../examples/functional/src/countdown.rs}}
let mut iter = Countdown::new(3);
assert_eq!(iter.size_hint(), (3, Some(3)));
assert_eq!(iter.next(), Some(3));
assert_eq!(iter.size_hint(), (2, Some(2)));
assert_eq!(iter.by_ref().count(), 2);
assert_eq!(iter.size_hint(), (0, Some(0)));
assert_eq!(iter.next(), None);
```

The remaining positive values are counted by the
field. Its zero branch yields None without updating
it, preserving both bounds.

### EX-C038-03 — Check lazy mapping

```rust,edition2021
{{#include ../examples/functional/src/countdown.rs}}
use std::cell::Cell;
let calls = Cell::new(0);
let mut iter = Countdown::new(8).map(|value| {
    calls.set(calls.get() + 1);
    value * 2
});
assert_eq!(calls.get(), 0);
assert_eq!(iter.next(), Some(16));
assert_eq!(calls.get(), 1);
```

The adapter already stores the source and closure.
The closure body runs only when the adapter obtains
an item to transform.

### EX-C038-04 — Implement an ascending byte iterator

```rust,edition2021
struct Below { current: u8, limit: u8 }

impl Iterator for Below {
    type Item = u8;
    fn next(&mut self) -> Option<u8> {
        if self.current == self.limit {
            return None;
        }
        let value = self.current;
        self.current += 1;
        Some(value)
    }
}

assert_eq!((Below { current: 0, limit: 0 }).next(), None);
let mut maximal = Below { current: 0, limit: u8::MAX };
assert_eq!(maximal.by_ref().last(), Some(254));
assert_eq!(maximal.next(), None);
```

Starting at zero and only incrementing when below
the limit maintains `current <= limit`. One step
can reach 255, but the equality check then prevents
another increment. The output excludes the limit.

### EX-C038-05 — Compare absence contracts

```rust,edition2021
fn pulses() -> impl Iterator<Item = u8> {
    let mut step = 0_u8;
    std::iter::from_fn(move || {
        let value = match step {
            0 => Some(7),
            2 => Some(9),
            _ => None,
        };
        step = step.saturating_add(1);
        value
    })
}

let mut raw = pulses();
assert_eq!([raw.next(), raw.next(), raw.next()], [Some(7), None, Some(9)]);
let mut fused = pulses().fuse();
assert_eq!([fused.next(), fused.next(), fused.next()], [Some(7), None, None]);
```

One consumer may stop at the first None in either
case. A later call on the original iterator can still
observe 9. The fused view supplies the stronger
promise across all later calls.

### Interview answers for Chapter 038

**IQ-C038-01.** An iterator can update sequence state
as it produces each result. The mutable receiver
allows that traversal while retaining ownership of the
iterator with the caller.

**IQ-C038-02.** Creating the adapter stores a source
and operation. It applies the operation when items are
demanded, so a prefix consumer may cause less work.
