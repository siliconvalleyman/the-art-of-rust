## Chapter 037

### EX-C037-01 — Borrow a lookup table

```rust,edition2021
{{#include ../examples/functional/src/callbacks.rs}}
let lookup = [22, 11];
let sample = sample_two(|index| lookup[usize::from(index)]);
assert_eq!(sample, [22, 11]);
assert_eq!(lookup[0], 22);
```

The lookup is captured and borrowed for the calls.
The two indices are supplied by the helper, one per
call. The original array remains available.

### EX-C037-02 — Accumulate with a mutable capture

```rust,edition2021
{{#include ../examples/functional/src/callbacks.rs}}
let mut count = 0;
visit_all(&[5, 6, 8, 4], |item| {
    if item > 5 { count += 1; }
});
assert_eq!(count, 2);
visit_all(&[], |_| count += 1);
assert_eq!(count, 2);
```

Only 6 and 8 meet the strict predicate. The visitor
can mutate the captured count. An empty slice performs
no calls, so the second operation leaves it unchanged.

### EX-C037-03 — Preserve repeated calls after move capture

```rust,edition2021
let label = String::from("parcel");
let measure = move || label.len();
assert_eq!(measure(), 6);
assert_eq!(measure(), 6);
```

Creation moves the String into the closure. Invoking
it only borrows the stored String to read its length.
The fixture shows that this move still invalidates
the old name.

### EX-C037-04 — Return the captured owner

```rust,edition2021
{{#include ../examples/functional/src/callbacks.rs}}
let label = String::from("parcel");
let owned = make_once(move || label);
assert_eq!(owned, "parcel");
```

The result takes ownership from the environment.
An Fn caller has only shared access to that
environment and cannot move this String out
through such access.

### EX-C037-05 — Observe an effect through Fn

```rust,edition2021
use std::cell::Cell;
fn twice<F: Fn() -> u8>(f: F) -> [u8; 2] {
    [f(), f()]
}

let counter = Cell::new(0);
let trace = twice(|| {
    let next = counter.get() + 1;
    counter.set(next);
    next
});
assert_eq!(trace, [1, 2]);
assert_eq!(counter.get(), 2);
```

The closure captures the cell through a shared
borrow. The Cell method permits mutation through that
path. Replacing the call with its first returned value
would skip the counter update.

### Interview answers for Chapter 037

**IQ-C037-01.** Capturing by value determines where
the environment lives. Fn is possible if each invocation
can work with shared access to that environment.

**IQ-C037-02.** FnMut supports repeated calls with
exclusive access to the callable. FnOnce alone does not
provide repeated use of the same instance.
