## Chapter 020

### EX-C020-01 — Report a checked range of pages

Length zero admits no page. Length one ends at address
15 and covers only page 0. Length two ends at address
16 and covers pages 0 and 1. Use the last included
address and divide both endpoints by 16 with integer
division. Dividing the exclusive end would wrongly
include an adjacent page in the length-one case.

### EX-C020-02 — Distinguish empty and overflowing ranges

```rust,edition2021
fn last_address(start: u64, length: u64) -> Result<Option<u64>, &'static str> {
    if length == 0 {
        return Ok(None);
    }
    start.checked_add(length - 1).map(Some).ok_or("overflow")
}

assert_eq!(last_address(u64::MAX, 0), Ok(None));
assert_eq!(last_address(u64::MAX, 1), Ok(Some(u64::MAX)));
assert_eq!(last_address(u64::MAX, 2), Err("overflow"));
```

Length one covers the greatest representable address.
Its exclusive end cannot fit, and requiring that end
would reject a range whose included addresses all fit.
The zero branch also avoids subtracting one from zero.

### EX-C020-03 — Check a span's permissions

Compute the pages for the whole byte range and reject
the request if any covered page lacks the permission.
Bytes 14 through 17 cover pages 0 and 1. The read
passes the permission check, while the write fails on
page 1. Bytes 32 through 33 cover page 2. A read
passes the permission check but needs residency
resolution. The write fails because page 2 is read-only.
Checking only the starting page misses page 1 in the
first case.

### EX-C020-04 — Count faults at two capacities

Capacity two faults on all nine demands. After the
initial two demands it holds the two most recent
different pages, so the next distinct demand faults
and preserves that invariant. With three frames, each
initial page faults once. All three pages then remain
in the cache, and subsequent accesses hit. Report nine
and three faults respectively, with no timing inference.

### EX-C020-05 — Set both a byte and page limit

Reject invalid page size first, then reject length
above 16. Compute the checked page span. An empty
span succeeds, and a nonempty span succeeds exactly
when the two page numbers agree. A valid two-byte
request at 14 stays in page 0. A three-byte request
there includes page 1 and fails. Length 17 fails the
byte limit before computing a span. Checking length
alone would accept the boundary-crossing case.

### Interview answers for Chapter 020

page have consecutive offsets inside one frame. At a
page boundary, the following page may map to a frame

**IQ-C020-02.** Capacity describes how much storage the
collection may use under the allocation interface.
The OS can resolve residency lazily or evict eligible
pages. Evidence about future faults needs the target
and its memory behavior, not just a returned capacity.
