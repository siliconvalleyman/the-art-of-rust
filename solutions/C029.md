## Chapter 029

### EX-C029-01 — Give the units distinct types

```rust,edition2021
#[derive(Debug, PartialEq, Eq)]
struct Millimeters(u16);
struct Centimeters(u16);

fn to_mm(value: Centimeters) -> Option<Millimeters> {
    value.0.checked_mul(10).map(Millimeters)
}

assert_eq!(to_mm(Centimeters(0)), Some(Millimeters(0)));
assert_eq!(to_mm(Centimeters(7)), Some(Millimeters(70)));
assert_eq!(to_mm(Centimeters(6553)), Some(Millimeters(65530)));
assert_eq!(to_mm(Centimeters(6554)), None);
```

Multiplication by ten is the conversion. The greatest
accepted input is `floor(65535 / 10) = 6553`.
Simply renaming the wrapped number changes its unit
without changing its value.

### EX-C029-02 — Reject a fractional conversion

```rust,edition2021
#[derive(Debug, PartialEq, Eq)]
struct Grams(u32);
struct Milligrams(u32);

fn whole_grams(value: Milligrams) -> Option<Grams> {
    if value.0 % 1000 == 0 {
        Some(Grams(value.0 / 1000))
    } else {
        None
    }
}

assert_eq!(whole_grams(Milligrams(4000)), Some(Grams(4)));
assert_eq!(whole_grams(Milligrams(4500)), None);
```

Zero remainder is exactly the divisibility condition.
Division alone would truncate 4,500 to 4. That could
be an explicit rounding policy, but it violates this
exactness requirement.

### EX-C029-03 — Derive a constructor contract

```rust,edition2021
mod shelf {
    #[derive(Debug, PartialEq, Eq)]
    pub struct Position(u8);

    impl Position {
        pub fn new(value: u8) -> Option<Self> {
            (1..=24).contains(&value).then_some(Self(value))
        }
    }
}

use shelf::Position;
assert!(Position::new(1).is_some());
assert!(Position::new(24).is_some());
assert_eq!(Position::new(0), None);
assert_eq!(Position::new(25), None);
```

Only an inclusive match returns the wrapper. In this
implementation `then_some` eagerly evaluates its
argument, so the transient private wrapper is constructed
even on rejection. No invalid value is returned. An
ordinary `if` or lazy `then` would also prevent internal
construction on the failure path.

### EX-C029-04 — Add at the policy boundary

```rust,edition2021
{{#include ../examples/data-modeling/src/weight.rs}}
let weight = ParcelWeight::new(Grams::new(29_999)).unwrap();
assert_eq!(weight.with_packaging(Grams::new(0)), Ok(weight));
assert_eq!(weight.with_packaging(Grams::new(1)).unwrap().grams().value(), 30_000);
assert_eq!(weight.with_packaging(Grams::new(2)), Err(WeightError::TooHeavy));
assert_eq!(weight.with_packaging(Grams::new(u32::MAX)), Err(WeightError::TooHeavy));
```

Zero packaging leaves the same weight. One reaches
the admissible endpoint. Two produces a representable
sum that fails the policy. The last addition cannot
fit the machine type, and its mathematical value
also violates the policy.

### EX-C029-05 — Audit all mutation paths

```rust,edition2021
mod measures {
    pub struct Volume(u16);

    impl Volume {
        pub fn new(value: u16) -> Option<Self> {
            (1..=100).contains(&value).then(|| Self(value))
        }

        pub fn update(&mut self, value: u16) -> Option<()> {
            *self = Self::new(value)?;
            Some(())
        }

        pub fn value(&self) -> u16 {
            self.0
        }
    }
}

let mut volume = measures::Volume::new(20).unwrap();
assert_eq!(volume.update(0), None);
assert_eq!(volume.value(), 20);
assert_eq!(volume.update(100), Some(()));
assert_eq!(volume.value(), 100);
```

Returning `&mut u16` would let the caller assign zero
directly. The replacement validates before assignment.
Failure returns early and leaves the original value
intact. Clamping invalid values would hide rejected input.

### Interview answers for Chapter 029

**IQ-C029-01.** An alias is another name for the same
type. A wrapper has a different identity, so calls
require the named unit. The arithmetic conversion still
needs to be correct.

**IQ-C029-02.** Construction establishes the property
only for the initial value. An exposed writable
reference can bypass validation. Each public update
path must preserve the same predicate.
