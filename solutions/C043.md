## Chapter 043

### EX-C043-01 — Preserve the error cause

```rust,edition2021
{{#include ../examples/reliability/src/row_errors.rs}}
let error = parse_row(9, "300").unwrap_err();
assert_eq!(error.line(), 9);
assert_eq!(error.to_string(), "invalid quantity on line 9");
assert!(error.source().unwrap().is::<ParseIntError>());
```

The number is above 255, so no `u8` can represent it. The failure
keeps enough structure to inspect the parse classification later.

### EX-C043-02 — Avoid disclosing a field

Format `invalid quantity on line N` with the line number supplied
by the importer. A malformed quantity field could accidentally hold
private data copied from another spreadsheet column. A caller who
already has permission to read the file can use the row location.

### EX-C043-03 — Walk the chain deliberately

```rust,edition2021
{{#include ../examples/reliability/src/row_errors.rs}}

fn chain_len(mut current: &(dyn Error + 'static)) -> usize {
    let mut count = 1;
    while let Some(cause) = current.source() {
        count += 1;
        current = cause;
    }
    count
}

assert_eq!(chain_len(&parse_row(1, "bad").unwrap_err()), 2);
```

This chain terminates at the parse error. If arbitrary implementations
can return a cycle, establish termination separately or limit the
number of sources visited.

### EX-C043-04 — Classify two parse failures

```rust,edition2021
{{#include ../examples/reliability/src/row_errors.rs}}
use std::num::IntErrorKind;

for (input, expected) in [("300", IntErrorKind::PosOverflow),
    ("cat", IntErrorKind::InvalidDigit)]
{
    let error = parse_row(1, input).unwrap_err();
    let source = error.source().unwrap().downcast_ref::<ParseIntError>().unwrap();
    assert_eq!(source.kind(), &expected);
}
```

The concrete type's error kinds encode the distinction independently
of the words chosen for the message.

### EX-C043-05 — Add importer-level context

```rust,edition2021
{{#include ../examples/reliability/src/row_errors.rs}}

#[derive(Debug)]
struct ImportError(RowError);

impl fmt::Display for ImportError {
    fn fmt(&self, out: &mut fmt::Formatter<'_>) -> fmt::Result {
        out.write_str("inventory import failed")
    }
}

impl Error for ImportError {
    fn source(&self) -> Option<&(dyn Error + 'static)> {
        Some(&self.0)
    }
}

let error = ImportError(parse_row(7, "bad").unwrap_err());
assert_eq!(error.to_string(), "inventory import failed");
let row = error.source().unwrap().downcast_ref::<RowError>().unwrap();
assert_eq!(row.line(), 7);
let cause = row.source().unwrap().downcast_ref::<ParseIntError>().unwrap();
assert!(cause.source().is_none());
```

The chain has three entries. The import layer supplies the operation,
the row supplies its location, and the parse layer records its reason.

### Interview answers

- **IQ-C043-01.** Call `Error::source` and inspect the returned trait
  object. A downcast can recover a known concrete type by reference.
- **IQ-C043-02.** The bound constrains the erased type to contain no
  borrowed data that would shorten the type's validity below `'static`.
  The outer reference is still tied to the borrow of the wrapper.
