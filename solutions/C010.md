## Chapter 010

### EX-C010-01 — Count a triangular loop

Each visited pair is an unordered pair with the smaller
index written first. Return `choose(n, 2)` using the
Chapter 9 implementation. The count is 0 for `n = 0`
and `n = 1`. For `n ≥ 2` the bounds `n²/4` and
`n²/2` establish `Θ(n²)`. Counting visits to both
`(i,j)` and `(j,i)` would double the constant term
but represent a different loop.

### EX-C010-02 — Count a search with repeated matches

Start at index 0 and compare to the target once per
position. If equal, return that index and its index plus
one as the comparison count. If all comparisons fail,
return absence and the input length. The prefix already
examined lacks any match, so a returned match appears first.
The example returns index 0 with one comparison for 5,
and absence with three comparisons for 4. A last-occurrence
algorithm would report index 2 for 5. Its presence boolean
would agree with the required algorithm without satisfying
the specified index or comparison count.

### EX-C010-03 — Compute an expected count exactly

Substitute `p/q` for `q` in the chapter's miss
probability expression, treating `q` here as an integer
denominator. Combining the terms over denominator
`2q` gives numerator `(q−p)(n+1) + 2pn`. For
`n = 7`, `p = 1`, `q = 4`, the numerator is 38
and denominator is 8, equivalent to `19/4`. Widen
each input before computing. The second term alone can
exceed a 64-bit integer at full input width, so use 128
bits. Reject a zero denominator, `p > q`, and an
empty list under the declared nonempty workload.
Treating the miss path as a uniformly distributed hit
would undercount its contribution.

### EX-C010-04 — Count array copies without simulating elements

Start at capacity 1 and accumulate that capacity while
it is less than `n`. Double capacity after accounting
for each growth. For the requested sizes, the answers
are 0, 0, 1, 3, 7, and 15. After `k` iterations
the current capacity is `2^k` and all previous growth
copies have been counted exactly once. Since the capacity
doubles, the stopping number of iterations is
`ceil(log₂ n)` for `n ≥ 1`. Widen a fixed-width
input if the next capacity may exceed its range. Counting
copies at capacity `n` would charge a growth that no
insertion actually requires.

### EX-C010-05 — Compare cumulative growth policies

The first insertion copies zero existing elements. The
second copies one, the third two, and insertion number
`n` copies `n−1`. The total is `n(n−1)/2` and
grows as `Θ(n²)`. At `n = 5`, capacity-by-one
copies 10 items while doubling copies 7. Growing by
one ends each insertion with no unused slots, whereas
doubling can leave spare capacity. The model compares
copies and unused capacity. It says nothing specific
about allocator metadata or wall-clock delay.

### Interview answers for Chapter 010

**IQ-C010-01.** For `n ≥ 1`, a quadratic count
is at most a constant multiple of `n³). There is
no positive fixed multiplier of `n³` that stays below
a quadratic count for arbitrarily large `n`. A cubic
bound is therefore a valid upper bound without being tight.

**IQ-C010-02.** A growth insertion can copy all current
items. The amortized claim bounds total work for a
sequence divided by its length. Doubling limits the
frequency and sum of expensive growth steps, while
ordinary insertions help bound their average charge.
