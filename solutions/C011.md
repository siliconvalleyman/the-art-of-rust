## Chapter 011

### EX-C011-01 — Print two exact lines

```rust,edition2021
fn main() {
    println!("Workshop open.");
    println!("Check in here.");
}
```

The first statement runs before the second. Each invocation
adds one newline after its text. Full credit requires two
lines with the punctuation shown and an explanation of the
execution order. Putting both sentences in one literal
with a space between them would produce one line.

### EX-C011-02 — Preserve punctuation in a literal

```rust,edition2021
fn main() {
    println!("Ready! (local)");
}
```

The mark in `println!` is part of the invocation syntax
and the outside parentheses delimit the macro input. The
mark after `Ready` and the parentheses around `local` are
literal characters. The printed line ends with a newline.
Removing the exclamation mark from the string changes the
observed output while leaving the source valid.

### EX-C011-03 — Repair the macro invocation

Change the invocation from `println("Hello, Rust!");`
to `println!("Hello, Rust!");`. The inserted `!`
immediately follows the name. It selects the macro
invocation syntax. The original exclamation mark is
between the quotes and appears in the output. A correct
diagnosis names the invocation before the string, reports
the compiler version, and demonstrates a successful build
and run after the edit. Editing the punctuation inside
the quotes cannot repair an invocation parsed as a
function call.

### EX-C011-04 — Reproduce the output through Cargo

Use `cargo +1.75.0 new --bin --edition 2021 --vcs none workshop-note`
outside an existing Cargo workspace. In the new package,
confirm the `[package]` table contains `edition = "2021"`.
Set `src/main.rs` to the following code.

```rust,edition2021
fn main() {
    println!("Bring a notebook.");
}
```

From that package directory, `cargo +1.75.0 run` builds
and runs the binary. The program's stdout is
`Bring a notebook.` followed by a newline. The
command's `+1.75.0` selector and the manifest's
`edition` entry fulfill different requirements. Using
edition 2021 alone would allow a different compatible
compiler release.

### EX-C011-05 — Distinguish build and run evidence

The first source has `fn main() { println!("sample A"); }`.
After changing only the literal, the file contains
`fn main() { println!("sample B"); }`. The existing
executable keeps printing `sample A` until a successful
rebuild replaces it. The next invocation of the rebuilt
file prints `sample B`. Require a successful build,
run the intended output path immediately afterward, and
compare its captured stdout with the expected bytes.
Observing a successful exit without checking the text
would pass both versions.

### Interview answers for Chapter 011

**IQ-C011-01.** Edition 2021 chooses language conventions
for the package. Compiler 1.75.0 identifies a specific
release of the tool that processes the source. A package
can keep its edition while switching compatible compiler
releases. Equating the numbers confuses language
configuration with release selection.

**IQ-C011-02.** Capture the binary's stdout and compare
it with the specified text, including case and line
ending. The exit status checks termination status. It
cannot distinguish two successful runs that emit
different characters.
