### EX-C026-01 — Count a finite product

```rust,edition2021
let mut pairs = Vec::new();
for width in [20_u16, 40] {
    for height in [10_u16, 30, 50] {
        pairs.push((width, height));
    }
}
assert_eq!(pairs, [(20, 10), (20, 30), (20, 50), (40, 10), (40, 30), (40, 50)]);
```

Every width is visited once and enumerates all three
heights. Two output positions differ in width or in
height, so each pair is unique. Adding the two domain
sizes would count component choices separately instead of
their assignments.

### EX-C026-02 — Name two equally typed fields

```rust,edition2021
struct Counts { received: u32, completed: u32 }

impl Counts {
    fn pending(&self) -> Option<u32> {
        self.received.checked_sub(self.completed)
    }
}

assert_eq!(Counts { received: 0, completed: 0 }.pending(), Some(0));
assert_eq!(Counts { received: 8, completed: 3 }.pending(), Some(5));
assert_eq!(Counts { received: 3, completed: 4 }.pending(), None);
```

The shared method observes both fields and leaves them
unchanged. Checked subtraction distinguishes a legitimate
zero from an inconsistent snapshot. Saturation would
collapse those cases.

### EX-C026-03 — Select a constructor and a receiver

```rust,edition2021
struct QueueNumber(u16);

impl QueueNumber {
    fn new(value: u16) -> Self { Self(value) }

    fn next(&self) -> Option<Self> {
        self.0.checked_add(1).map(Self)
    }
}

let current = QueueNumber::new(17);
assert_eq!(current.next().unwrap().0, 18);
assert_eq!(current.0, 17);
assert!(QueueNumber::new(u16::MAX).next().is_none());
```

The method reads the old number and constructs a fresh
wrapper when the next number fits. It need not borrow
mutably or take ownership. The maximum test detects
accidental wrapping.

### EX-C026-04 — Prove field exchange

```rust,edition2021
{{#include ../examples/data-modeling/src/dimensions.rs}}
let mut dimensions = Dimensions::new(23, 47);
dimensions.rotate();
assert_eq!(dimensions, Dimensions::new(47, 23));
dimensions.rotate();
assert_eq!(dimensions.into_pair(), (23, 47));
```

A rotation maps the ordered pair `(w, h)` to
`(h, w)`. Repeating it gives `(w, h)`. Testing
only two rotations would also pass for a no-op.
The assertion after one rotation distinguishes those
implementations.

### EX-C026-05 — Consume or borrow an owned record

```rust,edition2021
struct Record { id: u32, name: String }

impl Record {
    fn name(&self) -> &str { &self.name }
    fn into_name(self) -> String { self.name }
}

let record = Record { id: 4, name: String::from("label") };
assert_eq!(record.name(), "label");
assert_eq!(record.id, 4);
let name = record.into_name();
assert_eq!(name, "label");
```

The shared method ties the view to a borrow of the
record. The consuming method transfers its String field
to the result. The caller owns that buffer and cannot
use the moved-from record. Adding `clone` inside the
consuming method would copy data without preserving any
record for the caller.

### Interview answers for Chapter 026

**IQ-C026-01.** A value chooses one member from each
domain, with every combination permitted. Each distinct
sequence of choices gives one record. Cross-field
restrictions can reduce the admissible set.

**IQ-C026-02.** Shared use requires a compatible
borrow. A mutable receiver requires exclusive writable
access for the call. By-value use supplies the
instance itself and can move it from its prior owner.
