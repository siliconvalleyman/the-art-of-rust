### EX-C047-01 — Trace the new head

```rust,edition2021
{{#include ../data-structures/src/linked.rs}}

let mut list = FrontList::new();
for tree in ["oak", "ash", "elm"] {
    list.push_front(tree.to_owned());
}
assert_eq!(list.pop_front().as_deref(), Some("elm"));
assert!(list.iter().map(String::as_str).eq(["ash", "oak"]));
```

Insertion prepends, so `elm` became the last head installed.
The removal returns it by value. The iterator borrows the others.

### EX-C047-02 — Add a shared front query

```rust,edition2021
{{#include ../data-structures/src/linked.rs}}

impl<T> FrontList<T> {
    fn front(&self) -> Option<&T> {
        self.head.as_deref().map(|node| &node.value)
    }
}

let mut list = FrontList::new();
assert!(list.front().is_none());
list.push_front(3);
assert_eq!(list.front(), Some(&3));
assert_eq!(list.pop_front(), Some(3));
assert!(list.front().is_none());
```

The front reference comes from a shared borrow of the whole list.
`pop_front` needs a mutable borrow and may remove the referenced
element. Rust only allows the mutable borrow after the last use of
the outstanding shared reference.

### EX-C047-03 — Append through empty states

```rust,edition2021
use std::collections::LinkedList;

let mut destination = LinkedList::new();
let mut source = LinkedList::from([4, 9]);
destination.append(&mut source);
assert!(destination.iter().copied().eq([4, 9]));
assert!(source.is_empty());
destination.append(&mut source);
assert!(destination.into_iter().eq([4, 9]));
assert!(source.is_empty());
```

In the first operation there is no old tail to connect to the
source's first node. The destination can take the endpoints as a
pair. In the second there is no incoming chain, so existing links
need no change.

### EX-C047-04 — Reconstruct a wrapped traversal

The physical order is `6, 7, 0, 1, 2`. The first span has two
items by `min(5, 8 - 6) = 2`, and the second has the remaining
three. A valid front and length no greater than capacity ensure
that at most one wrap is needed. In general, `c - first` is the
number of slots remaining before the ring ends. Take the shorter
of that number and `len`, then put the rest at index zero.

### EX-C047-05 — Repair a doubly linked removal

For `B`, assign `A.next = C` and `C.prev = A`, obtaining `A, C, D`.
Only setting `A.next` would leave `C.prev` pointing at the removed
node. For `D`, set `C.next` to absent and set the tail to `C`,
obtaining `A, C`. Removing `A` makes `C` the head and clears
`C.prev`. Removing the final `C` clears both endpoints. Any actual
implementation must ensure no owning or observing handle can still
use the detached nodes after deallocation.

### Interview answers

- **IQ-C047-01.** The Box is a fixed-size owning handle to a node.
  Its ownership can express one finite successor chain without
  making each node contain another node inline.
- **IQ-C047-02.** Traversing the first slice and then the second
  yields logical front-to-back order. The public contract does not
  make a caller's layout-dependent choice of split valid.
