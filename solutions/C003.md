## Chapter 003

### EX-C003-01 — Select exactly the intended alarm rows

Use `(sensor_a OR sensor_b) AND (NOT maintenance)`. The
maintenance bit is the rightmost bit in the rows below.

| Input row | Output |
| --- | ---: |
| 000 | 0 |
| 001 | 0 |
| 010 | 1 |
| 011 | 0 |
| 100 | 1 |
| 101 | 0 |
| 110 | 1 |
| 111 | 0 |

All rows with maintenance enabled are suppressed. With
maintenance disabled, at least one fault suffices. XOR would
incorrectly suppress row 110. Award credit for including that
case and checking suppression independently of the sensors.

### EX-C003-02 — Build a selector with NAND

```text
not_enable = NAND(enable, enable)
left = NAND(old, not_enable)
right = NAND(new, enable)
selected = NAND(left, right)
```

The last NAND produces the OR of the two uninverted selection
terms by De Morgan's law. At enable 0 it produces old, so
inputs `(0, 1)` and `(1, 0)` yield 0 and 1. At enable
1 they yield 1 and 0, respectively. There are four two-input
gates. Omitting `not_enable` makes both terms vanish when
enable is 0. Grade the intermediate terms as well as the rows.

### EX-C003-03 — Verify a full adder by enumeration

**Executable Rust preview.**

```rust,edition2021
{{#include ../examples/foundations/src/logic.rs:full_adder}}
for a in [false, true] {
    for b in [false, true] {
        for carry_in in [false, true] {
            let (sum, carry_out) = full_adder(a, b, carry_in);
            let expected = u8::from(a) + u8::from(b) + u8::from(carry_in);
            assert_eq!(u8::from(sum) + 2 * u8::from(carry_out), expected);
        }
    }
}
```

The column total for `1, 0, 0` is 1. Reversing a correct
pair returns a carry of 1 and a sum of 0, reconstructing 2.
Comparing the unweighted count of set output bits would
miss that defect. Each of the eight inputs appears once
by construction. The mathematical proof relates the two
half adders to the specification before enumeration.

### EX-C003-04 — Swap two registers at an edge

Take a snapshot `(a, b)` of the current state. Return
`(b, a)` when enabled, or `(a, b)` when disabled. Commit
both next values together. The states after the three edges
are `(1, 0)`, `(1, 0)`, and `(0, 1)`. An enabled step
applied twice gives `(a, b)` for any bits `a` and `b`.
An in-place first assignment followed by reading that updated
bit for the second assignment misses this property when the
bits initially differ.

### EX-C003-05 — Reduce a zero detector

OR neighboring bits to get four signals. OR neighboring
signals to get two, then OR the pair and invert the result.
Each internal signal is 1 if at least one descendant bit is 1.
The invariant starts with each original bit and is preserved
by OR. The final inversion detects that no descendant is 1.
Either single-1 edge case makes the root OR high and the
detector low. The tree uses `4 + 2 + 1 = 7` OR gates in
three layers, plus the NOT. A serial chain uses the same
gate count with seven OR layers on its longest path. This
compares dependencies under a gate-depth model, with no
timing claim about fabricated hardware.

### Interview answers for Chapter 003

**IQ-C003-01.** On `1, 1` XOR gives 0 and OR gives 1. If
1 means a fault, an alert should usually remain active when
there are two faults. A claim that XOR behaves like OR for
two signals misses the simultaneous-report case.

**IQ-C003-02.** Identify signal paths, gate and wire delays,
load, clock period, and the timing assumptions at the receiving
register. An analysis or measurement with those assumptions
can establish timing for that implementation. Equal tables
only establish equal stable logical outputs.
