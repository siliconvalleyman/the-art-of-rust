## Chapter 031

### EX-C031-01 — Select an element without copying

```rust,edition2021
fn second<T>(values: &[T]) -> Option<&T> {
    values.get(1)
}

assert_eq!(second::<u8>(&[]), None);
assert_eq!(second(&[3]), None);
assert_eq!(second(&[3, 7]), Some(&7));
```

Index one is the second position. A borrow of the
element needs no independent copy. Returning index
zero would pass a presence-only test on length two.

### EX-C031-03 — Move independent values

```rust,edition2021
{{#include ../examples/abstractions/src/generic.rs}}
let pair = Pair::new(String::from("keep"), true);
let reversed: Pair<bool, String> = pair.reversed();
assert_eq!(reversed.into_parts(), (true, String::from("keep")));
```

The new first field is Boolean. Copying the original
type order into the return type would still require
the String first. Such a body cannot implement a
reversal for arbitrary distinct types.

### EX-C031-04 — Require equal lengths

```rust,edition2021
fn shared_length<A, B, const N: usize>(_: &[A; N], _: &[B; N]) -> usize {
    N
}

assert_eq!(shared_length(&[0_u8; 0], &['a'; 0]), 0);
assert_eq!(shared_length(&[4_u8; 3], &[false; 3]), 3);
```

The two element types vary independently. Both
array inputs constrain the same constant, so different
lengths would not agree on any value of `N`.

### EX-C031-05 — Audit an accidental bound

```rust,edition2021
fn first_two<T>(values: &[T]) -> Option<(&T, &T)> {
    Some((values.first()?, values.get(1)?))
}

struct Reading(u16);
let list = [Reading(2), Reading(3)];
let (a, b) = first_two(&list).unwrap();
assert_eq!((a.0, b.0), (2, 3));
assert!(first_two(&list[..1]).is_none());
```

The index checks establish that the references point
into the borrowed slice. The output lifetime derives
from the input. A local clone would be a different
owner, and returning a borrow of that local value
would fail the lifetime contract.

### Interview answers for Chapter 031

**IQ-C031-01.** The signature defines all permitted
instantiations. The body must type-check using the
guarantees common to those instantiations. A special
operation for integers needs a restriction or a
different function.

**IQ-C031-02.** Repeating `T` requires both fields
to have the same type at a given instantiation.
Independent parameters let the two fields have
different types.
