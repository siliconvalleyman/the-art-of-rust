## Chapter 007

### EX-C007-01 — Find the remaining jobs

Return requested AND (bitwise NOT cached), with all
operations confined to eight bits. At each position,
the output is 1 precisely when the request bit is 1 and
the cache bit is 0. In the example only position 3 meets
both conditions. A zero request or a full cache yields 0.
Using XOR would also include cache-only positions, which
are outside the requested set.

### EX-C007-02 — Show why shared inputs fail equivalence

Write these rows in job order, using 1 for nonempty
intersection: `[1, 1, 0]`, `[1, 1, 1]`, and
`[0, 1, 1]`. An intersection exists in both orders,
so the matrix is symmetric. Job 0 overlaps job 1 and
job 1 overlaps job 2, but job 0 and job 2 do not
overlap. To generate entry `(i, j)`, search for an ID
in list `i` that occurs in list `j`. Duplicating an ID
does not change whether the witness exists. Award credit
for a concrete witness for each true relation and an
explicit missing edge in the transitivity counterexample.

### EX-C007-03 — Compose two prerequisite steps

Test each vertex `k` for `edge[i][k] AND edge[k][j]`.
Return true on success. On each continued iteration all
visited candidates were ruled out, so reaching the end
establishes there is no walk of length two. From parse
to package the result is true. The lone `0 → 2` edge
does not give a length-two walk. A self-edge gives a
two-edge walk from its vertex to itself because this query
allows revisiting vertices. Invalid indices are separate
from a valid negative result.

### EX-C007-04 — Find a partial mapping collision

Enumerate the first index from 0 upward. For each first
index, enumerate later indices in increasing order and
compare the two slot values. Return at the first match.
At the start of each comparison every earlier pair in
that order has failed. Hence the returned pair is
lexicographically first and an exhausted search proves
absence. The example returns `(0, 3)`. A search ordered
by the second index would instead return `(1, 2)`. A
no-match list of length `n` yields
`n(n − 1)/2` pairs, with two indices needed for traversal.

### EX-C007-05 — Model an inverse

Start with an array of three empty inverse entries. For
each job, reject a slot outside 0 through 2. Reject a
slot if that entry is already occupied, otherwise store
the current job index in that slot. Distinct valid
assignments by all three jobs occupy all three entries.
The output maps each slot to the unique job that maps
to it. The first example yields `[1, 2, 0]`. The
second has a collision at slot 0 and leaves slot 1 unused
by the original input. The third has an index outside the
domain. Overwriting a duplicate would silently destroy
one assignment and fail the inverse equations.

### Interview answers for Chapter 007

**IQ-C007-01.** Require exactly one assigned worker for
each job in the domain. Giving each job at most one worker
leaves the unassigned case. If unassigned is valid, include
an explicit absent value in the codomain.

**IQ-C007-02.** A walk from A to B and one from B to C
can be joined to give reachability from A to C. A direct
edge from A to B followed by one from B to C supplies two
edges and need not supply the single edge A to C. State
which fact the relation records before testing transitivity.
