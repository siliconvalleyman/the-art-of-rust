## Chapter 008

### EX-C008-01 — Sum first integers at full width

Widen `n` to 64 bits. Compute `n × (n+1) / 2`.
The base is a sum of zero terms. Adding the next term
to the assumed formula at `k` gives the formula at
`k+1`. For the largest 32-bit input the product is
`2^64 − 2^32`, so the division is performed on a
representable unsigned value. Outputs are 0, 1, 5050,
and 9,223,372,034,707,292,160. Widening after computing
the successor of the largest input would already have
exceeded the 32-bit bound.

### EX-C008-02 — Construct a postage representation

For amounts below 8 the representable values are 0,
3, 5, and 6, with count pairs `(0,0)`, `(1,0)`,
`(0,1)`, and `(2,0)`. No larger count of either
denomination fits that range. At 8 or more, compute
`offset = (n−8) mod 3`. Choose base `8 + offset`,
with counts `(1,1)`, `(3,0)`, or `(0,2)`.
Because `offset ≤ n−8`, subtracting the base is safe.
Add `(n−8−offset) div 3` to the number of threes.
The reconstructed value is exactly `n` and neither
count exceeds `n`. This rule rejects 4 and 7, handles
all three bases, and gives `(5,1)` for 20. A largest-first
rule can fail on 9.

### EX-C008-03 — Derive leaf counts

Return `(1,0)` for a leaf. For a binary internal
node, recursively obtain the two pairs. Sum their leaf
components and sum their internal components plus 1.
For the described tree the right subtree yields `(2,1)`,
and the root produces `(3,2)`. The base obeys
`L = I + 1`, and combining two such children with one
new internal node preserves the equality. A unary node
with a single leaf child gives `(1,1)`, which refutes
the identity on an enlarged domain. If each node costs a
constant number of operations, the work is proportional
to node count. Auxiliary stack grows with the longest
root-to-leaf path.

### EX-C008-04 — Verify a balanced-work predictor

For an argument at most 1 return zero. Otherwise
compute `left = n div 2` and `right = n − left`,
and return `n + oracle(left) + oracle(right)`. The
split partitions the original input. For 7 this
requires sizes 3 and 4, yielding total 20. For 8 it
uses 4 and 4, yielding total 24. If only the split of 7
rounds both sizes down, the resulting two size-3
subproblems yield 17 total. Applying the defective rule
again at each size-3 split yields 13 total.
The comparison checks all arguments in the stated finite
test range. Award credit for preserving the sum of
subproblem sizes and explaining what the oracle verifies.

### EX-C008-05 — Count decimal digits by division

Return 1 for 0. Otherwise set count to 0 and repeatedly
divide the remaining positive value by 10, rounding down,
and increment count. One division removes exactly the
least significant decimal digit. After `k` divisions,
`k` positions have been removed and the quotient
contains the unprocessed high positions. The positive
quotient strictly decreases on every division, so
the algorithm terminates when the high positions are
exhausted. The tests give 1, 1, 2, 2, 3, and 10.
The number of divisions equals the answer for each
positive input. A loop with no explicit zero case would
give zero digits for the representation `0`.

### Interview answers for Chapter 008

**IQ-C008-01.** The step is an implication. It can hold
without its hypothesis holding at any index. The base
case gives the first actual proposition to which the
implication can be applied. For example, `n < 0`
is false for every nonnegative `n`, and the implication
from `k < 0` to `k+1 < 0` holds vacuously over
that indexing domain.

**IQ-C008-02.** Integer division rounds down. Applying
it twice discards an item from the modeled subproblems.
At size 5, the halves must be 2 and 3. Losing the final
item changes exact work and can change the actual result
when the recurrence models computation over the data.
