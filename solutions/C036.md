## Chapter 036

### EX-C036-01 — Evaluate the independent functions

```rust,edition2021
{{#include ../examples/functional/src/quotes.rs}}
assert_eq!(base_price(0), 0);
assert_eq!(quote(0), 0);
assert_eq!(base_price(1), 125);
assert_eq!(quote(1), 113);
assert_eq!(base_price(3), 375);
assert_eq!(quote(3), 338);
```

The rounded discount values are 0, 12, and 37.
Rounding the final price down instead would give
112 or 337 for the nonintegral examples.

### EX-C036-02 — Pass the policy as an input

```rust,edition2021
fn subtotal(count: u16, rate: u16) -> u32 {
    u32::from(count) * u32::from(rate)
}

assert_eq!(subtotal(5, 125), 625);
assert_eq!(subtotal(u16::MAX, u16::MAX), 4_294_836_225);
```

Widen both inputs first. The exact product of
their largest values fits. Reading a mutable global
would allow the same written arguments to produce a
different result when the rate changes.

### EX-C036-03 — Distinguish two compositions

For three items, a subtotal of 375 has a discount
of 37 and gives 338 cents. Discounting the count
first subtracts zero from three, and the resulting
subtotal stays 375. The functions have similar
arithmetic, but the units being rounded differ.

### EX-C036-04 — Separate rendering from writing

```rust,edition2021
{{#include ../examples/functional/src/quotes.rs}}
fn publish(count: u16, output: &mut impl std::io::Write) -> std::io::Result<()> {
    output.write_all(receipt(count).as_bytes())
}

let mut bytes = Vec::new();
publish(3, &mut bytes).unwrap();
assert_eq!(bytes.as_slice(), b"items=3, cents=338");
```

The receipt test checks stored bytes independently of
a terminal. A writer that returns a deliberate error
can test that the boundary forwards the failure.
A memory writer alone does not exercise that path.

### EX-C036-05 — Make the observation boundary explicit

The global counter changes on every quote call.
Substituting the price preserves the number and skips
the update, so a later read can distinguish the
programs. Keep updating the counter at the boundary.
Pass the count and policy to a numeric function that
uses no request-counter state.

### Interview answers for Chapter 036

**IQ-C036-01.** No. A function can compute a number
and also write output, consult external state, or
change state. Inspect the operations in its body
and those it calls.

**IQ-C036-02.** Replacing an expression is valid only
for the behavior being compared. A returned price
can be equivalent in value while evaluation time
or resource use differs.
