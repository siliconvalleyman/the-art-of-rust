## Chapter 040

### EX-C040-01 — Test duplicate and threshold handling

```rust,edition2021
{{#include ../examples/functional/src/prefixes.rs}}
let values = [3, 7, 7, 5, 8];
assert!(qualified_prefix(&values, 7, 3).eq([7, 7, 8]));
assert!(qualified_prefix(&values, 7, 0).eq([]));
assert!(qualified_prefix(&[], 7, 3).eq([]));
```

Threshold equality qualifies. The two copies of 7
come from different positions and both must appear.
Deduplicating would violate the sequence contract.

### EX-C040-02 — Detect the wrong adapter order

```rust,edition2021
{{#include ../examples/functional/src/prefixes.rs}}
let input = [1, 8, 7, 9];
assert!(qualified_prefix(&input, 7, 2).eq([8, 7]));
assert!(input.into_iter().take(2).filter(|&n| n >= 7).eq([8]));
```

Taking first fixes which input positions can be
examined. Filtering first lets the request count
qualifying values instead.

### EX-C040-03 — Count actual predicate calls

```rust,edition2021
use std::cell::Cell;
let input = [1, 8, 2, 7, 5, 9];
let calls = Cell::new(0);
let qualifies = |&value: &u16| {
    calls.set(calls.get() + 1);
    value >= 7
};

let bounded: Vec<_> = input.into_iter().filter(qualifies).take(2).collect();
assert_eq!(bounded, [8, 7]);
assert_eq!(calls.get(), 4);
calls.set(0);
let all: Vec<_> = input.into_iter().filter(qualifies).collect();
assert_eq!(all, [8, 7, 9]);
assert_eq!(calls.get(), 6);
```

The second match occurs at the fourth input. A
consumer requesting all matches reaches the last.
The counter records logical calls and establishes no
machine timing.

### EX-C040-04 — Compare with a reference model

```rust,edition2021
{{#include ../examples/functional/src/prefixes.rs}}
fn eager(values: &[u16], minimum: u16, count: usize) -> Vec<u16> {
    let mut output = Vec::new();
    for &value in values {
        if value >= minimum { output.push(value); }
    }
    output.truncate(count);
    output
}

for limit in 0..=5 {
    let values = [6, 7, 7, 4];
    assert!(qualified_prefix(&values, 7, limit).eq(eager(&values, 7, limit)));
    assert!(qualified_prefix(&values, 10, limit).eq(eager(&values, 10, limit)));
}
```

The reference examines all values while the other
may stop early. Agreement checks the output
contract under different traversal strategies.

### EX-C040-05 — Choose a return interface

```rust,edition2021
{{#include ../examples/functional/src/prefixes.rs}}
fn owned_prefix(values: &[u16], minimum: u16, count: usize) -> Vec<u16> {
    qualified_prefix(values, minimum, count).collect()
}
let selected = {
    let input = vec![1, 8, 7];
    owned_prefix(&input, 7, 2)
};
assert_eq!(selected, [8, 7]);
```

The Vec owns its result and can outlive the input.
The constructor still only demands the bounded prefix.
It must hold the resulting items in its own storage,
while a borrowed iterator can supply them one at a time.

### Interview answers for Chapter 040

**IQ-C040-01.** It exposes the stated traits and
item type while the implementation selects the
concrete adapter type. It also exposes any lifetime
requirement stated by the signature.

**IQ-C040-02.** If the input contains fewer qualifying
values than requested, the consumer must inspect all
positions to establish that there are no more matches.
The kth match can also occur at the last position.
