## Chapter 004

### EX-C004-01 — Separate address and value

The loads read from `0x1000` and `0x1004`. The first pair
sets `x7` to 32, or `0x20`. After the branch the PC is
`0x210`. The store writes `20 00 00 00` at `0x1008`.
For zero inputs the loads use the same addresses, `x7`
is 0, and the branch goes to `0x214`. The four
destination bytes remain `ff ff ff ff`. A trace that
reports a stored zero misses the taken branch. Award credit
for identifying when memory is read and when it is changed.

### EX-C004-02 — Encode an instruction by fields

Place source 2 at bit 20, source 1 at bit 15, destination 3
at bit 7, and use opcode `0x33`. The other fields are 0.
The result is `0x002081b3`, stored as `b3 81 20 00`.
Reading the five positions at 24–20, 19–15, and 11–7 yields
2, 1, and 3. Swapping the sources gives `0x001101b3`.
The same sum can occur with both encodings. Credit requires
correct bytes and correct recovery of the independent fields.

### EX-C004-03 — Implement a cache trace

Start with two empty slots. For each address, find
`line = address div 4` and `slot = line mod 2`. Emit a
hit when the selected slot already holds that line. Install the
line and advance. The invariant is that each occupied slot
holds the most recently requested line mapped there. Initially
neither slot has such a request. After serving an address,
only the selected slot changes to reflect the latest request.
This preserves the invariant. The finite index increases for
each iteration, and the output decisions are in input order.

The specified sequence gives miss, hit, miss, hit, miss, miss.
Empty input yields an empty decision stream. Using the number
0 for emptiness would give a false hit on the first access.
For `n` addresses the simulator takes `n` constant-cost
steps, two slots, and `n` output decisions if materialized.

### EX-C004-04 — Predict exact misses

Compute the quotient `q = n div 4` and remainder
`r = n mod 4`. Return `q` when `r = 0` and `q + 1`
otherwise. Each full four-byte group begins a distinct line,
and a nonempty short group adds one final line. This is
constant work on a fixed-width input and avoids computing
`n + 3`, which could exceed the type's maximum value.
The formula also gives 0 for empty input. Simply returning
`q` misses a partial final line.

### EX-C004-05 — Find a conflict pair

The first positive line in slot 0 is line 2 at byte address 8.
The sequence `[0, 8, 0, 8, 0, 8]` accesses slot 0 each
time. After the initial miss, the slot always holds the
other line just before an access. The address 4 belongs to
line 1 in slot 1. Alternating 0 and 4 misses for the first
access to each slot, then hits four times. Credit requires an
argument based on the slot calculation, including why 4 does
not evict line 0.

### Interview answers for Chapter 004

**IQ-C004-01.** RV32I gives the base register width and
architectural instructions. The cache organization is a
separate design property. Inferring a common line size from
the ISA designation generalizes beyond the contract.

**IQ-C004-02.** Reordering can change which requests occur
between reuses. In the model, `[0, 0, 8, 8]` gives two
misses but `[0, 8, 0, 8]` gives four. Both have two
requests to each byte. The intervening conflict explains the
difference that a set or count of addresses misses.
