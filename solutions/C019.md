## Chapter 019

### EX-C019-01 — Measure total and contiguous capacity

```rust,edition2021
fn free_space(free: &[bool]) -> (usize, usize) {
    let mut total = 0;
    let mut run = 0;
    let mut longest = 0;
    for &available in free {
        if available {
            total += 1;
            run += 1;
            longest = longest.max(run);
        } else {
            run = 0;
        }
    }
    (total, longest)
}

assert_eq!(free_space(&[true, true, false, true]), (3, 2));
assert_eq!(free_space(&[]), (0, 0));
assert_eq!(free_space(&[false, false]), (0, 0));
```

Track total free slots in the processed prefix, its
current free suffix, and the maximum suffix reached.
Those quantities start at zero and update exactly as
the next status requires. Total and maximum differ
because the occupied slot separates the two free runs.

### EX-C019-02 — Find the first sufficient run

For `[true,true,false,true,true]` and length two,
the earliest end is index 1 and the result is 0.
For `[false,true,true]` the first fit ends at index
2 and gives start 1. After an unsuccessful inspection
one fewer slot remains. The suffix invariant from the
chapter handles positive results and proves absence at
the end. Counting all free slots could bridge an
occupied slot incorrectly.

### EX-C019-03 — Coalesce adjacent intervals

Keep the latest merged range. When its end equals
the next range's start, extend its end. Otherwise
emit it and start a new range. Emit the final range
if present. Two meeting half-open intervals contain
exactly the indices in their combined interval because
the endpoint belongs only to the second part. The
example yields `[0,7), [9,11)`. A chain
`[0,1), [1,2), [2,3)` merges to `[0,3)`, and
empty input emits nothing. Merging across a gap would
claim an occupied position is free.

### EX-C019-04 — Count misses under changing capacity

At capacity three, the initial three distinct line
requests all miss. Afterwards the cache holds the
previous three distinct lines, and the next line in the
cycle is never one of them. There are sixteen misses.
At capacity four, all four lines are resident after
the first column and every remaining request hits.
There are four misses. Award credit for reasoning after
the cache first fills as well as the initial misses.

### EX-C019-05 — Compare fixed size classes

The first class system reserves 4, 8, 8, and 16,
totaling 36. The requests sum to 25, so the excess
is 11. Adding class 12 changes only the 9-slot
placement to 12, giving total 32 and excess 7. In an
ascending class list, reject zero first and return the
first value at least the request. If no class fits,
return an error. A class smaller than the request
cannot supply the required region. Whether the new size
class improves the entire allocator also depends on
how space is divided among the classes.

### Interview answers for Chapter 019

**IQ-C019-01.** The free space can be divided by live
allocations, leaving no sufficiently large contiguous
range. Eligible aligned starts can constrain fit further.
Reporting only the total misses both conditions.

**IQ-C019-02.** Check the actual layout, hierarchy,
cache behavior, and workload. Measure traffic or time
with controlled inputs and configurations if the
conclusion concerns a real machine. A count under one
replacement policy does not directly determine elapsed time.
