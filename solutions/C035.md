## Chapter 035

### EX-C035-01 — Mark two units

```rust,edition2021
{{#include ../examples/abstractions/src/lending.rs}}
struct Grams;
struct Milliliters;
let mass = Quantity::<Grams>::new(17);
let volume = Quantity::<Milliliters>::new(17);
assert_eq!(mass.amount(), volume.amount());
assert_eq!(std::mem::size_of_val(&mass), std::mem::size_of_val(&volume));
```

The wrapper has one numeric payload in each case.
The unit parameters still name different types.
A function using Quantity of Grams requires that
type regardless of the sizes.

### EX-C035-02 — Accept a fresh borrow for each call

```rust,edition2021
{{#include ../examples/abstractions/src/lending.rs}}
fn count_letters(text: &str) -> usize {
    text.bytes().filter(|byte| byte.is_ascii_alphabetic()).count()
}
assert_eq!(inspect_two(count_letters), [4, 5]);
```

Both sample words contain only ASCII letters.
A static-only callback cannot be called with a
borrow of a String whose owner ends inside the
inspector. The higher-ranked requirement includes
that shorter lifetime.

### EX-C035-03 — Derive the number of windows

```rust,edition2021
{{#include ../examples/abstractions/src/lending.rs}}
fn count(bytes: &mut [u8], width: NonZeroUsize) -> usize {
    let mut windows = ByteWindows::new(bytes, width);
    let mut total = 0;
    while windows.next().is_some() {
        total += 1;
    }
    total
}

assert_eq!(count(&mut [], NonZeroUsize::new(2).unwrap()), 0);
assert_eq!(count(&mut [0; 4], NonZeroUsize::new(2).unwrap()), 3);
assert_eq!(count(&mut [0; 4], NonZeroUsize::new(1).unwrap()), 4);
assert_eq!(count(&mut [0; 4], NonZeroUsize::new(4).unwrap()), 1);
```

If width fits, the last start is length minus
width. Counting from zero includes that start.
Otherwise there is no valid start. Subtracting width
before checking it could underflow on empty input.

### EX-C035-04 — Repair a conflicting window borrow

```rust,edition2021
{{#include ../examples/abstractions/src/lending.rs}}
let mut bytes = [1, 2, 3];
let mut windows = ByteWindows::new(&mut bytes, NonZeroUsize::new(2).unwrap());
let first = windows.next().unwrap();
first[1] = 7;
let second = windows.next().unwrap();
second[0] = 8;
assert_eq!(bytes, [1, 8, 3]);
```

Index one of the first view and index zero of
the second view name the same byte. The last
use of `first` precedes the second call. The
later write replaces the earlier one without
requiring the two borrows to coexist.

### EX-C035-05 — Separate callback output from its input

```rust,edition2021
fn with_text<F>(callback: F) -> String
where
    F: for<'a> Fn(&'a str) -> String,
{
    let temporary = String::from("inspection");
    callback(&temporary)
}

let kept = with_text(str::to_owned);
assert_eq!(kept, "inspection");
```

The returned String owns its storage. A callback
with output `&'a str` tied to this input would
produce a view of data supported only within
the call. Returning that view to the outer
caller would require a different lifetime source.

### Interview answers for Chapter 035

**IQ-C035-01.** Layout describes storage. Distinct
type arguments can constrain operations and calls
even when they need no extra stored bytes.

**IQ-C035-02.** The item borrows the source's
storage. Tying it to the current exclusive loan
stops the caller from requesting a second
potentially overlapping mutable view while the
first remains usable.
