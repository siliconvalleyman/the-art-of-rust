## Chapter 039

### EX-C039-01 — Observe adapter order

```rust,edition2021
let first: Vec<_> = [1, 3, 4].into_iter().map(|n| n + 1).filter(|n| n % 2 == 0).collect();
let second: Vec<_> = [1, 3, 4].into_iter().filter(|n| n % 2 == 0).map(|n| n + 1).collect();
assert_eq!(first, [2, 4]);
assert_eq!(second, [5]);
```

In the first chain the even result corresponds
to odd inputs. In the second the filter inspects
the original even input 4. The item selection
is therefore different.

### EX-C039-02 — Supply a fold identity

```rust,edition2021
fn sum(values: &[u8]) -> Option<u32> {
    values.iter().try_fold(0_u32, |total, &value| total.checked_add(u32::from(value)))
}
assert_eq!(sum(&[]), Some(0));
assert_eq!(sum(&[255, 1]), Some(256));
```

The initial zero is the sum of the empty prefix.
Widening each input before addition allows a sum
above 255. Checked addition also handles a total
that does not fit in the accumulator type.

### EX-C039-03 — Preserve empty input in a reduction

```rust,edition2021
fn smallest(values: &[u8]) -> Option<u8> {
    values.iter().copied().reduce(u8::min)
}
assert_eq!(smallest(&[]), None);
assert_eq!(smallest(&[u8::MAX]), Some(u8::MAX));
assert_eq!(smallest(&[18, 4, 6]), Some(4));
```

The first item establishes the nonempty prefix
minimum. Replacing it with the smaller of itself
and the next value maintains the property.
Choosing an initial maximum byte would obscure
the distinction for empty input.

### EX-C039-04 — Find the first parse or sum failure

```rust,edition2021
{{#include ../examples/functional/src/reductions.rs}}
assert_eq!(sum_fields(&["4294967295", "1", "x"]), Err(SumError::Overflow(1)));
assert_eq!(sum_fields(&["1", "x", "3"]), Err(SumError::InvalidField(1)));
```

Addition of one fails at the second field of the
first input. In the second input no number can be
obtained from that field. A separate eager parsing
phase could report a later malformed field first.

### EX-C039-05 — Demonstrate unconsumed suffix work

```rust,edition2021
let mut fields = ["2", "x", "4"].into_iter();
let result: Result<u32, &str> = fields.try_fold(0_u32, |total, field| {
    let value = field.parse::<u32>().map_err(|_| field)?;
    total.checked_add(value).ok_or(field)
});
assert_eq!(result, Err("x"));
assert_eq!(fields.next(), Some("4"));
```

The call obtains the successful first item and
the failing second item. It returns at the second.
The third remains in the source and is obtained
only by the later explicit request.

### Interview answers for Chapter 039

**IQ-C039-01.** Fold returns its supplied accumulator
when no item is consumed. Reduce has no first item
to use in that case, so it returns None.

**IQ-C039-02.** Multiple failures can be possible in
one input. Parsing everything first can expose a
later parse failure before aggregation reports an
earlier overflow. A streaming chain can define
failure in input order.
