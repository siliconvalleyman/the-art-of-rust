## Chapter 024

### EX-C024-01 — Shorten a shared reference

Use the chapter's `shorter` signature. The returned
view uses the marker's borrowed region. A static source
covers that region. A borrowed local value may cease
to be valid when its owner leaves scope and therefore
cannot generally become static.

### EX-C024-02 — Separate the lifetimes of a slot

```rust,edition2021
fn put<'loan, 'data>(slot: &'loan mut &'data str, data: &'data str) {
    *slot = data;
}

let mut slot: &'static str = "before";
put(&mut slot, "after");
assert_eq!(slot, "after");
```

This uses a short loan of a slot whose stored type
demands static text. The written value must satisfy
the inner promise. Changing the outer region never
removes that requirement.

### EX-C024-03 — Reproduce and repair the invariant slot

Replacing `local.as_str()` with a literal preserves
the slot's static guarantee. Removing the explicit
static annotation can let the slot store the local
borrow as long as the caller's later uses fit its
scope. Credit requires that the first repair retain
the type and the second keep the owning source alive.

### EX-C024-04 — Substitute a consumer

```rust,edition2021
fn run(handler: fn(&'static str) -> usize) -> usize {
    handler("fixed")
}

fn count(input: &str) -> usize {
    input.len()
}

assert_eq!(run(count), 5);
```

Every static text reference is a valid input for
`count`. The callback is valid for a wider family
of lifetimes than the caller uses. A static-only
consumer would fail to meet a caller's contract if
that caller could supply an arbitrary local borrow.

### EX-C024-05 — Find the missed mutability path

```rust,edition2021
use std::cell::Cell;

let counter = Cell::new(1);
let first = &counter;
let second = &counter;
first.set(4);
assert_eq!(second.get(), 4);
```

Both references reach the same cell. Its safe method
changes the value. Covariance for a cell containing a
reference would let a weaker view replace the original
value with one whose referent ends sooner. A later read
through the stronger view could then make a promise the
replacement cannot meet.

### Interview answers for Chapter 024

**IQ-C024-01.** The outer lifetime describes the loan
of the slot. The inner one describes which reference
values the slot may store. A short loan does not
weaken the type of the borrowed slot.

**IQ-C024-02.** A stronger guarantee can be weakened
when reading a value. If writing accepted the weaker
type, new contents could violate what a later reader
expects. Invariance prevents that substitution.
