### EX-C046-01 — Trace a stack and a queue

```rust,edition2021
{{#include ../data-structures/src/linear.rs}}
let mut stack = Stack::new();
let mut queue = Queue::<_, 2>::new();
for color in ["red", "blue"] {
    stack.push(color.to_owned());
    queue.push(color.to_owned()).unwrap();
}
assert_eq!(stack.pop().as_deref(), Some("blue"));
assert_eq!(queue.pop().as_deref(), Some("red"));
assert_eq!(stack.pop().as_deref(), Some("red"));
assert_eq!(queue.pop().as_deref(), Some("blue"));
```

The stack removes `blue` because it was inserted last. The queue
removes `red` because it was inserted first. The code moves each
owned string out of its container.

### EX-C046-02 — Count work for geometric growth

| Push | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Capacity afterward | 1 | 2 | 4 | 4 | 8 | 8 | 8 | 8 | 16 |
| Existing values moved | 0 | 1 | 2 | 0 | 4 | 0 | 0 | 0 | 8 |

The counted total is 15 relocations plus nine insertions, or 24.
The tenth push uses spare capacity and adds one insertion to the
total. This is the specified geometric model, whose capacity choices
need not match a particular `Vec` implementation.

### EX-C046-03 — Verify the full-state contract

```rust,edition2021
{{#include ../data-structures/src/linear.rs}}
let mut queue = Queue::<_, 1>::new();
queue.push(String::from("first")).unwrap();
let pending = queue.push(String::from("second")).unwrap_err();
assert_eq!(pending, "second");
assert_eq!(queue.pop().as_deref(), Some("first"));
queue.push(pending).unwrap();
assert_eq!(queue.pop().as_deref(), Some("second"));
```

Returning the value transfers it back to the caller. Retrying uses
the same value and succeeds once capacity is available.

### EX-C046-04 — Bound the wrapped tail index

```rust,edition2021
fn wrapped_index(head: usize, offset: usize, capacity: usize) -> usize {
    assert!(head < capacity && offset < capacity);
    let suffix = capacity - head;
    if offset < suffix {
        head + offset
    } else {
        offset - suffix
    }
}

assert_eq!(wrapped_index(usize::MAX - 1, 2, usize::MAX), 1);
assert_eq!(wrapped_index(1, 1, 3), 2);
assert_eq!(wrapped_index(1, 2, 3), 0);
```

The mathematical sum in the first case is `usize::MAX + 1`. A
machine addition can overflow before the remainder is taken. The
branch uses `suffix = 1`, then `2 - 1`. More generally the first
branch computes a sum strictly below capacity, and the second
computes a nonnegative difference that is also below capacity.

### EX-C046-05 — Compare against an independent queue model

```rust,edition2021
{{#include ../data-structures/src/linear.rs}}
use std::collections::VecDeque;

for history in 0..16 {
    let mut actual = Queue::<_, 2>::new();
    let mut expected = VecDeque::new();
    for step in 0..4 {
        if history & (1 << step) == 0 {
            let expected_push = if expected.len() == 2 {
                Err(step)
            } else {
                expected.push_back(step);
                Ok(())
            };
            assert_eq!(actual.push(step), expected_push);
        } else {
            assert_eq!(actual.pop(), expected.pop_front());
        }
        assert_eq!(actual.len(), expected.len());
    }
    let drained: Vec<_> = std::iter::from_fn(|| actual.pop()).collect();
    assert!(drained.into_iter().eq(expected));
}
```

Each bit chooses a push or pop for that position. The pushed value
uses the step number so a wrong order can be detected even when all
scheduled operations are pushes. The 16 histories cover four calls
starting empty with capacity two. They say nothing by themselves
about longer histories, other capacities, or nontrivial destructors.

### Interview answers

- **IQ-C046-01.** Length counts initialized elements. Capacity counts
  how many elements can fit in the current backing storage before a
  growth is needed.
- **IQ-C046-02.** An individual push may allocate and move the current
  elements. Under geometric growth, the capacity-sized relocation
  work sums linearly across a long sequence of pushes.
