## Chapter 032

### EX-C032-01 — Give a type an associated label

```rust,edition2021
trait Sample {
    const LABEL: &'static str;
    fn value(&self) -> u8;
}

struct Counter(u8);
impl Sample for Counter {
    const LABEL: &'static str = "items";
    fn value(&self) -> u8 { self.0 }
}

assert_eq!(Counter::LABEL, "items");
assert_eq!(Counter(17).value(), 17);
```

Each instance provides its own numeric value.
The label belongs to the implementation and
does not need to be stored per Counter.

### EX-C032-02 — Reuse a default method

```rust,edition2021
trait Amount {
    fn number(&self) -> u8;
    fn is_zero(&self) -> bool { self.number() == 0 }
}

struct Counter(u8);
impl Amount for Counter {
    fn number(&self) -> u8 { self.0 }
}

assert!(Counter(0).is_zero());
assert!(!Counter(1).is_zero());
```

The default relies only on the required method.
An implementation of Amount can therefore reuse
the check without exposing internal storage.

### EX-C032-03 — Bound the associated type

```rust,edition2021
{{#include ../examples/abstractions/src/reading.rs}}
struct Manual(u32);
impl Reading for Manual {
    type Unit = Grams;
    const LABEL: &'static str = "g";
    fn value(&self) -> u32 { self.0 }
}
assert_eq!(total_grams(&[Manual(7), Manual(2)]), Some(9));
```

Manual chooses the required associated type.
Volume chooses Milliliters, so its Reading
implementation by itself does not satisfy the
equality. Matching a label's text would not
establish type identity.

### EX-C032-04 — Use a supertrait

```rust,edition2021
{{#include ../examples/abstractions/src/reading.rs}}
fn describe<R: BoundedReading>(reading: &R) -> (u32, bool) {
    (reading.value(), reading.is_within_limit())
}

assert_eq!(describe(&Weight(30_000)), (30_000, true));
assert_eq!(describe(&Weight(30_001)), (30_001, false));
```

The bound supplies both capabilities. There is
no separate requirement to write `R: Reading`
since it follows from BoundedReading.

### EX-C032-05 — Prove overflow cannot be corrected

```rust,edition2021
{{#include ../examples/abstractions/src/reading.rs}}
assert_eq!(total_grams::<Weight>(&[]), Some(0));
assert_eq!(total_grams(&[Weight(u32::MAX - 1), Weight(1)]), Some(u32::MAX));
assert_eq!(total_grams(&[Weight(u32::MAX), Weight(1), Weight(0)]), None);
```

Each prefix sum is at most every later prefix
sum when additions are nonnegative. A prefix over
the limit therefore proves final failure. With signed
8-bit inputs, `[127, 1, -1]` has an intermediate sum
128 and a final sum 127. A final-range contract would
need a different accumulator or argument in that domain.

### Interview answers for Chapter 032

**IQ-C032-01.** An associated constant has one value
for the chosen implementation. A field belongs to
an instance and may vary across instances.

**IQ-C032-02.** An implementation of the stronger
trait must also have the supertrait implementation.
A generic caller with the stronger bound can use
the supertrait's operations without adding another
bound.
