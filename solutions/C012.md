## Chapter 012

### EX-C012-01 — Trace a mutable counter

```rust,edition2021
let mut count = 32_u16;
count += 6;
count += 9;
assert_eq!(count, 47);
```

The values are 32, 38, and 47. The `+=` operator
adds to and updates the existing binding. Removing
`mut` makes an update illegal. Credit requires
one binding and an accurate transition through 38.

### EX-C012-02 — Widen deliberately with shadowing

```rust,edition2021
let value = 250_u8;
let value = u16::from(value) + 10;
assert_eq!(value, 260_u16);
```

The original `u8` fits 250. The conversion takes place
before adding 10, so the operation is on a `u16`.
Adding in the byte type would require representing 260
there before the conversion. Use a fresh binding
because a reassignment keeps the original type.

### EX-C012-03 — Produce a block value

```rust,edition2021
const LIMIT: u16 = 100;
let seats = {
    let occupied = 21 + 17;
    LIMIT - occupied
};
assert_eq!(seats, 62);
```

`occupied` is inferred as `u16` from its use in
the subtraction. The final expression supplies
62. Adding a semicolon to the subtraction discards
its value and makes the block evaluate to unit,
which cannot satisfy the numeric assertion.

### EX-C012-04 — Compare two scopes

```rust,edition2021
let status = "outer";
{
    let status = "sample";
    assert_eq!(status, "sample");
}
assert_eq!(status, "outer");
```

Each initializer creates a binding used in its own
scope. Neither binding is reassigned, so neither needs
`mut`. Assigning into the outer binding would change
the value later observed after the block.

### EX-C012-05 — Make arithmetic grouping explicit

```rust,edition2021
let cups = 2_u16;
let plates = 3_u16;
let trays = 4_u16;
let total = (cups + plates) * trays;
assert_eq!(total, 20);
assert!(total >= 18);
assert_eq!(cups + plates * trays, 14);
```

Each tray has five items, so multiplying after the
addition gives 20. Without parentheses the multiplication
has higher precedence, and only the plates are multiplied
by the tray count. Credit requires both the expected
total and the Boolean check.

### Interview answers for Chapter 012

**IQ-C012-01.** Shadow with a new `let` declaration.
The new binding can have a different type. Reassigning a
mutable binding still requires a value of its existing type.

**IQ-C012-02.** The semicolon makes the expression a
statement whose result is discarded. A block with no
tail expression in this example has unit as its result.
A later numeric use can reveal the mismatch.
