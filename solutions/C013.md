## Chapter 013

### EX-C013-01 — Widen before taking an average

```rust,edition2021
fn average(a: u8, b: u8) -> u8 {
    let sum = u16::from(a) + u16::from(b);
    (sum / 2) as u8
}

assert_eq!(average(0, 0), 0);
assert_eq!(average(3, 4), 3);
assert_eq!(average(250, 20), 135);
assert_eq!(average(255, 255), 255);
```

The widened sum is at most 510, and its floor divided
by two is at most 255. This proves the cast preserves
the result. Widening after adding in the byte type
would leave the intermediate exposed to overflow.

### EX-C013-02 — Specify a wrapped sequence number

```rust,edition2021
fn advance(sequence: u8, step: u8) -> u8 {
    sequence.wrapping_add(step)
}

assert_eq!(advance(254, 1), 255);
assert_eq!(advance(254, 2), 0);
assert_eq!(advance(255, 255), 254);
```

The maximum ordinary sum is 510. Widening both operands
to `u16` before adding preserves the full sum. Casting
to a byte then keeps the low eight bits, equivalent to
reducing modulo 256. Saturating would return 255 for
the last two tests and implement a different contract.

### EX-C013-03 — Reject a truncating length conversion

```rust,edition2021
let cases = [0_u16, 255, 256].map(u8::try_from);
assert_eq!(cases[0], Ok(0));
assert_eq!(cases[1], Ok(255));
assert!(cases[2].is_err());
```

The limit includes 255. A cast would map 256 to zero,
an apparently valid empty payload length. Award credit
for demonstrating that failure and zero are distinct.

### EX-C013-04 — Require an exact byte-valued measurement

```rust,edition2021
fn exact_byte(value: f64) -> Option<u8> {
    if value.is_finite() && (0.0..=255.0).contains(&value) && value.trunc() == value {
        Some(value as u8)
    } else {
        None
    }
}

assert_eq!(exact_byte(-0.0), Some(0));
assert_eq!(exact_byte(255.0), Some(255));
for invalid in [12.5, 255.5, -1.0, f64::INFINITY, f64::NAN] {
    assert_eq!(exact_byte(invalid), None);
}
```

The successful guard establishes every property required
by the interface. Every integer from 0 to 255 has an exact
binary floating-point representation. Negative zero compares
equal to zero and converts to a zero byte. A check after
casting would see zero for both NaN and a valid zero.

### EX-C013-05 — Find a lost identifier

```rust,edition2021
let first = 1_u64 << 53;
let second = first + 1;
assert_ne!(first, second);
assert_eq!(first as f64, second as f64);
```

The second value lies halfway between representable
`f64` values. Rounding selects the lower one in this
case. Use an integer field for exact equality throughout
the full identifier domain. Equal converted values alone
cannot establish that the input identifiers were equal.

### Interview answers for Chapter 013

**IQ-C013-01.** Overflow checks can be enabled or disabled.
On a runtime byte addition that exceeds 255, the checked
operator panics, while the unchecked addition wraps.
An explicit method records the arithmetic policy in the
program itself.

**IQ-C013-02.** A float cast maps NaN to zero and can
also map negative finite values or positive fractions
below one to zero in an unsigned byte. Examine validity
before the cast discards those distinctions.
