# Code of conduct

Treat contributors and learners with respect. Critique the reasoning
and evidence, give people room to correct mistakes, and respect stated
names and boundaries. Harassment, threats, deliberate disclosure of
private information, and discriminatory behavior are unacceptable in
project spaces.

Use a private channel agreed with the repository owner to report an
incident, especially if it includes personal information. Include the
context necessary to review the incident. Maintainers may remove
harmful material, restrict participation, or close discussions as
appropriate. Protect the privacy of affected participants.
